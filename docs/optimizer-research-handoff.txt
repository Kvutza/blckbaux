3. What actually ran, mathematically

Source entry points:
  cuda/src/model/run.rs: hnet_bo_bench, enn_acquisition, descriptor_distance
  cuda/src/model/weights.rs: materialize_gaussian
  cuda/device/src/fbt.rs: gaussian_fp16

Audit the recorded revision plus patch before asserting exact reproducibility.
Current source and the saved result agree on these structural facts:

  - ENN-style inverse-distance surrogate, 32 nearest observations.
  - Sliding history of at most 128 observations.
  - Four proposed coefficient vectors, one selected function evaluation per round.
  - Gaussian coefficients and Thompson-labeled acquisition.
  - 70 explicit coordinates, one per resident tensor buffer.
  - Same prompt, targets, temperature and evaluation seed throughout.
  - radius = 0.1 throughout, including the long plateau.
  - Strict measured improvement is the acceptance rule.

The CUDA command accepts positional arguments. It does not execute all semantics
suggested by the accompanying TOML: corpus rotation, validation-interval, and the
Metal reliability trust-region rule are not established by that TOML. The CUDA
loop explicitly sets round_radius = radius and never adapts it. The `full_bo_loop`
flag establishes neither configuration parity nor mathematical equivalence with
the native Metal optimizer.

Let b index the 70 buffers and i a coordinate within a buffer. The implemented
candidate map is

  theta'_(b,i) = Q16(theta_(b,i) + r a_(b,i) z_b g_(b,i)),
  z_b ~ N(0,1).

Here Q16 is FP16 rounding, a is the stored block scale, and g is a fixed dense
pseudorandom normal field keyed by buffer index and coordinate. The counter key
for g is not refreshed by the proposal seed; the seed changes z. The posterior
coordinate is c' = c + r z. Acceptance moves both the weight center and c.

Conditional algebra, ignoring rounding and holding scales and g fixed:

  theta(c) = theta_0 + A c,   A in R^(D x 70),
  rank(A) <= 70,             Cov(delta) = r^2 A A^T.

Proof: column b of A contains a_(b,i)g_(b,i) on buffer b and zeros elsewhere.
Each increment is r A z. Accepted increments sum inside range(A).

Thus the real-valued proposal law is singular in D dimensions, even though an
individual update touches coordinates throughout the model. FP16 rounding can
break exact affine-subspace membership; it does not establish controllable
exploration of the missing directions. Changing scales or fields requires a new
reachable-space argument. This is a mathematical limitation of this branch,
not proof that it caused the observed plateau.

Its descriptor distance is
  d(c,c') = ||c-c'||_2^2 / 70.
The executed unquantized squared weight distance is
  ||A(c-c')||_2^2 = sum_b ||A_b||_2^2 (c_b-c'_b)^2.
These agree up to a common factor only under equal column energies. A comment
claiming that descriptor distance matches executed weight distance is insufficient.
Derive the metric, including scales, rounding, ties, and shared physical storage.
Do not automatically replace it with a costly matrix construction.

For a query c, the CUDA surrogate selects up to 32 nearest retained observations.
With stored reward y_j and variance v_j, it computes

  w_j = 1 / max(1e-9 + 0.05 d(c,c_j) + 0.05 + v_j, 1e-12),
  mu(c) = sum_j w_j y_j / sum_j w_j,
  sigma(c)^2 = (1 + sum_j w_j (0.05 + v_j)) / sum_j w_j.

This runner inserts v_j = 0. The constants are implementation settings, not
proved aleatoric or epistemic calibration. UCB returns mu + sigma. The Thompson
branch forms a normalized Gaussian weighted sum of neighbor noise and returns
mu + sigma Z(c). Each candidate is passed a different draw seed. Consequently,
the implementation does not share one noise value per observation across all
queries in a candidate pool. Do not transfer the shared-neighbor covariance
argument from the Metal sampler to this code. Independent marginal draws can
define a finite-pool model, but calling them Thompson sampling does not prove
that they represent the desired posterior over the objective function.

The coefficient center records cumulative real-valued increments, while the
weights undergo FP16 rounding after each accepted step. Bound or measure this
representation discrepancy before assuming the center identifies exact weights.

4. Objective, observations and valid claims

The retained scalar training objective is conditional cross-entropy. Formalize
its intended population version as

  F(theta) = E_(x,y)~D [ -(1/|y|) sum_t log p_theta(y_t | x,y_<t) ].

Specify whether population sampling weights episodes equally or tokens equally;
these differ for variable-length episodes. For this T4 benchmark D is replaced
by one fixed prompt/target pair. Audit the H-Net scorer to establish the precise
prefix used at each position and the compressed-state conditioning before
claiming equality with the formal expression. Generated text and reference
conditional scoring are distinct outputs of the same evaluation.

Black-box feedback can be vector-valued. Per-token or per-patch losses may retain
information discarded by a mean. They are not independent samples by default,
not gradients, and not separate optimization objectives merely because they
form a vector. A multi-output observation model for one scalar objective differs
from multi-objective BO. Do not invent new rewards, add KL objectives, or change
the target to improve the appearance of the curve.

For each proposal, the observation identity must include the actual candidate
state or reproducible construction, incumbent/reference state, episode, scoring
protocol, sampling/randomness, and objective value or response vector. A seed or
70-vector is not automatically a sufficient statistic for that identity or for
the objective posterior. Demonstrate the factorization or identifiability claim
before using the term sufficient statistic.

Keep conditional theorems distinct from measured outcomes. For a finite candidate
set C containing theta and exact fixed objective F, let theta* minimize F on C.
For the selected candidate theta_hat, define

  opportunity G = F(theta) - F(theta*) >= 0,
  selection regret R = F(theta_hat) - F(theta*) >= 0.
  F(theta) - F(theta_hat) = G - R.

This identity separates poor proposals from poor selection. The stored CUDA trace
only evaluates the selected candidate, so it cannot identify G or R for the whole
pool. No analysis of that trace alone can prove which term caused the plateau.

If a selector minimizes h within xi and |h-F| <= epsilon simultaneously on C,
then R <= 2 epsilon + xi. This follows by applying the error bound on theta_hat
and theta*, then the approximate-minimization inequality. These are assumptions
to establish, not properties implied by the ENN name. For Thompson acquisition,
h is the sampled selection function, not the posterior mean alone. Exploration
need not improve the objective every trial.

A monotone best-so-far curve follows mechanically from strict acceptance on a
fixed deterministic task. It does not by itself establish surrogate advantage,
convergence to a useful model, or generalization. No convergence or regret bound
for this implemented high-dimensional method has been established here. Do not
import GP/UCB, TuRBO or nearest-neighbor theorems without matching assumptions.

9. The CUDA correction and its verification

The first T4 `./blckbaux cuda model-check` passed the FP16 portion, then raised a
CUDA 719 fault. `./blckbaux cuda sanitize model-check` located an out-of-bounds
route-table read in `routed_compact` in `cuda/device/src/fbt.rs`. Its launch
allocates four 16-row subtiles per routed tile. The kernel had indexed the
route table with the raw Y block and started every subtile at row zero. Once Y
reached route-table capacity, it read beyond the table. That was an actual
correctness bug, not evidence that the workload simply needed fewer blocks.

Current kernel mapping in `cuda/device/src/fbt.rs`, around line 2908:

  let block = thread::blockIdx_y();
  let tile = block / 4;
  let first = (block % 4) * 16;
  routed::<64>(..., tile, first);

This retains the four-subtile launch schedule and makes each block use its
proper route tile and row offset. The patched kernel was uploaded and rebuilt
through `./blckbaux`. The post-fix T4 model-check passed all parity categories, and
the post-fix sanitizer reported `ERROR SUMMARY: 0 errors`. The T4 manifest
records the corrected kernel SHA-256:
e5079c64ffe69483d8f5ef4196c70edb2df2f7520fe445463bb3f19092062d21.

The A100 initially received an inconsistent stale source archive and failed to
build because `run.rs` and `readout.rs` disagreed. This was resolved by syncing

1. Lie algebra operator identities (`Optimization/LieOperator.lean`):
   Perturbations are generated via the Lie bracket generator
   Ω = [Wᵀ W, Σ_X] = (Wᵀ W) Σ_X - Σ_X (Wᵀ W).
   Checked theorems:
   - `commutatorSkew`: (commutator A B)ᵀ = -commutator A B for symmetric A, B.
   - `memSo`: commutator A B ∈ LieAlgebra.Orthogonal.so n ℝ.
   - `skewTrace`: trace (Ω * M) = 0 for skew Ω and symmetric M. This identity
     does not eliminate the quadratic curvature term of a weight perturbation.
   - `frobeniusInvariant`: trace ((W * Q) * (W * Q)ᵀ) = trace (W * Wᵀ) for any
     orthogonal Q ∈ Matrix.orthogonalGroup n ℝ, guaranteeing exact real energy
     conservation for that multiplication. No full-rank exploration theorem,
     objective-improvement theorem, or finite-precision refinement is supplied.

2. Forward constants and score-ordering lemma (`Semantics/FbtProgram.lean`):
   - `pisaBound` proves the declared constants satisfy 8 <= 64. It does not
     certify a traversal, token count, attention approximation, or runtime.
   - The stream, layer, and expert numbers are definitions; no recurrence or
     Sinkhorn implementation refinement is present in this module.
   - `cellInvar` proves pairwise score ordering survives shifts below half an
     explicit margin. A top-k set result needs the corresponding all-pairs
     hypotheses. `cellLip` only proves K * distance >= 0; objective Lipschitz
     continuity is unproved. `cellBound` defines a bounded-jump proposition;
     it does not prove that a model or controller satisfies it.

3. Workload constants and conditional algebra (`Optimization/PretrainWorkload.lean`):
   - Token budget, rounds, 200 ms target, arms, and neighbors are definitions.
   - `roundBound` takes its regret inequality as a hypothesis and unfolds a
     definition. It does not derive that inequality from the surrogate.
   - `cumulBound` sums a constant per-round bound to give T * boundVal.
   - `meanRegret` assumes R_T <= C * sqrt(T) and divides to get an average
     bound. It does not derive a shrinking regret rate or prove BLCKBAUX no-regret.
   - `flopDominance` rearranges an assumed improvement/cost ratio inequality.
     The 1.1 F / 3.5 F and 31.5% numbers in comments are not cost certificates.

14. Joint policy/certificate synthesis: first checked experiment, 2026-10-13

The current user-directed research is to find a Bayesian optimization algorithm

  research/lean/BlckbauxResearch/Optimization/Synthesis.lean

Regret.simpleRegret is the true terminal-objective gap to an explicit comparator.
Global optimality is an independent predicate on the state type. Its poolBound
theorem composes coverage with Selection.regretBound to give
  simple regret <= coverage + 2 * estimation error + selection slack.
The coverage and estimation hypotheses must still be established for BLCKBAUX.

Synthesis.Policy supplies initialization, query, update from typed feedback, and
recommendation. Objective and optimum are absent from that interface. An Oracle
provides a finite normalized conditional feedback law and natural-valued work
charges. The law may depend on time, retained memory, and queried state; this
does not prove that memory is sufficient for an actual application's law.

Certificate.regretBound derives expected terminal regret from initial potential,
one-step expected potential, and terminal domination inequalities.
Certificate.workBound derives a pathwise work budget from initial credit and
one-step charge/credit inequalities. These are reusable induction theorems.
Task fixes a nonempty environment class, horizon, bound, and work budget.
Solution contains one policy plus certificates for every environment in that
fixed class. It is the output type for joint algorithm/proof search.
Acceptance requires the policy and runtime dependencies to compile as ordinary
Lean definitions. Noncomputable analysis is permitted in certificate data, not
as a substitute for an executable policy. Audit theorem axioms and keep the
task definition fixed; changed assumptions/targets are separate proposals.

The first witness is deliberately a finite specification experiment, not a new
pretraining optimizer. Its computable policy queries both Boolean states,
retains two rational observations, and recommends the smaller observed score.
For every objective and oracle with uniform absolute observation error <= e,
Lean derives terminal simple regret <= 2e, on every path and in expectation.
At most two declared query work units are used. Exact observations give zero
regret. A constant recommendation fails on an admissible opposing objective;
a noisy tie attains the full 2e penalty. The build evaluates both score orderings.
Printed dependency audits show only standard propext, Classical.choice, and
Quot.sound axioms for the new checked results, without sorryAx or custom axioms.

Limits: no automated agent/search harness is installed, no global BO discovery
result is claimed, and no BLCKBAUX model run was launched. Rational storage is not
a finite-bit memory guarantee. Query work units are not FLOPs or wall time.
The 200 ms target and 1000 ms ceiling remain targets for complete transactions.
Continuous feedback laws, fresh policy randomness, justified pretraining
objective classes, finite-precision instantiation, shrinking regret rates, and
complete implementation/machine work accounting remain obligations.

     unexplored regions. If ŝ_t > z_max * (r_t ∨ s_t), q_t > z_max marks the step as
     INADEQUATE even if the predicted mean is exact (z_t = 0). The controller literally
     penalizes the surrogate for being honest about its epistemic uncertainty and rewards

     r_t ∝ ℓ. As r_t → 0, the denominator of sharpness shrinks, causing q_{t+1} to explode
     even higher. This guarantees subsequent rejections, driving ℓ geometrically down to
     length_min (0.0001) or below the discrete FP16/BF16 lattice separation δ.

23. Metric Space Adaptive k-NN Theory (Contemporary Research & Mathlib Formalization)

A. Why Adapting k from Historical Averages Fails:
  In high-dimensional black-box optimization over neural network parameters (1.18B parameters),
  the loss landscape is highly anisotropic:
  - In sharp directions (high local intrinsic dimension / large Hessian eigenvalues), loss varies
    rapidly over tiny metric distances. Large k introduces catastrophic metric bias.
  - In flat directions / manifold valleys (low local intrinsic dimension / flat subspace), loss is
    locally invariant. Small k fails to average out stochastic observation noise.
  - Storing global historical averages or cross-validating k across past rounds imposes a uniform
    rigidity that is miscalibrated whenever the optimizer traverses a new local regime.
  - Therefore, k must adapt locally per trial / candidate query without historical dependence.

B. Contemporary Research Papers & Theoretical Foundations:
  1. Local Intrinsic Dimension Adaptation (Samory Kpotufe, NeurIPS 2011):
     Proved that k-NN regression naturally achieves the minimax rate n^(-2/(d(x)+2)) governed by
     the local intrinsic dimension d(x) rather than the ambient dimension D. The metric ball
     radius R_k(x) shrinks as (k/n)^(1/d(x)).
  2. Local Bias-Variance Balancing & Lepski's Principle (Lepski 1990; Spokoiny 2001; Kpotufe & Garg 2013):
     At any query point x, candidate neighborhood expansion exhibits a strict monotonic tradeoff:
     - Metric Bias: L * R_k(x) is monotonically non-decreasing in k (pulling points from further away).
     - Variance / Stochastic Noise: σ / k is monotonically decreasing in k (averaging observations).
     - The optimal trial-adaptive choice k*(x) = argmin_k (L * R_k(x) + σ / k) requires no historical
       memory—it evaluates solely the candidate distance profile at the current trial.
     - Under Lepski's test, k is sequentially expanded as long as successive neighborhood means remain
       within the stochastic confidence corridor: |f̂_k(x) - f̂_{k'}(x)| ≤ 2 σ / √k'. The first failure
       pinpoints the onset of metric bias distortion.
  3. Non-Parametric Manifold Rates & Local Kernels (Taiji Suzuki, Masashi Sugiyama, Shinji Ito at RIKEN AIP / Tokyo):
     - Suzuki (2018, 2020): Fast non-asymptotic rates for deep representations under low-dimensional
       metric measure doubling conditions.
     - Sugiyama (2010, 2013): Local unconstrained least-squares fitting per test point for adaptive bandwidth.
     - Ito (2020, 2024): Parameter-free regret adaptivity to local variation.
  4. Metric Space Foundations (Kontorovich & Weiss 2014; Chaudhuri & Dasgupta 2014):
     Finite-sample nearest neighbor bounds formulated directly on abstract metric spaces (X, dist)
     via local covering numbers rather than Euclidean coordinates.

1. Deconstruction of the K = 4 Heuristic:
   - Root Origin: `CANDIDATES = 4` in `paired_response_reliability.rs` and `cuda/src/main.rs` was a legacy GPU warp-lane / 1x4 threadgroup layout constant, not an intrinsic optimization invariant.
   - High-Dimensional Zeroth-Order Barrier: In dimension $d \approx 1.178 \times 10^9$, isotropic gradient variance scales as $\mathcal{O}(d / K)$. Setting $K = 4$ reduces variance by a trivial factor of 4, leaving residual error variance of $\sim 2.5 \times 10^8$. Finite candidate widths cannot reconstruct full-parameter gradients without operator-subspace structure.
   - Extreme Value Selection Law: When treating $K$ as candidate acquisition pool (Thompson/UCB), maximal expected improvement scales sub-linearly as $\mathbb{E}[\max_{k \le K} (-\Delta L_k)] \le \sigma_L \sqrt{2 \ln K}$. Returns decay as $\frac{1}{K \sqrt{\ln K}}$.
   - Hardware Roofline Bound & Optimal $K^*$: In memory-bandwidth-bound transformer forward passes, weights are read once and reused across $K$ candidates. Arithmetic intensity $\mathcal{I}(K) \approx S \cdot K$. For context slice $S = 16$ on Apple Silicon (50 TFLOPS, 800 GB/s, knee at 62.5 FLOPs/B), $K = 4$ exactly hits the roofline knee. For $K \le 4$, evaluation latency $T(K) \approx \text{const}$; for $K > 4$, $T(K) \propto K$.
   - Throughput Optimality: Sequential progress $\Phi(K) = \frac{T_{\text{max}}}{T(K)} \sigma \sqrt{2 \ln K}$ is strictly decreasing for $K > K_{\text{roofline}}$ since $\frac{d}{dK}\left(\frac{\sqrt{\ln K}}{K}\right) < 0$ for $K > e^{1/2} \approx 1.65$. The optimal pool size $K^*$ is uniquely determined by the hardware arithmetic intensity knee, not an arbitrary constant.

2. Verified Formal Lean 4 Module (`BlckbauxResearch.Objective.Relative`):
   - `Group.sumZero`: $\sum_{i=1}^K (X_i - \bar{X}) = 0$.
   - `Group.shift`: Invariance under uniform difficulty/context offsets: $(X_i + c) - \overline{X + c} = X_i - \bar{X}$.
   - `Group.bound`: Cauchy-Schwarz universal bound: $(X_i - \bar{X})^2 \le \sum_{j=1}^K (X_j - \bar{X})^2$, guaranteeing that standardized group relative advantages are unconditionally bounded in $[-\sqrt{K}, \sqrt{K}]$ for any raw loss distribution.

32. SURROGATE FITTING AND NEIGHBOR SELECTION ARE INDEPENDENT
================================================================================

The version 3 optimizer schema now represents two distinct decisions:

  [optimizer.surrogate]
  neighbors = 10
  neighbor-rule = "fixed"          # or "risk-prefix"

  [optimizer.surrogate.fitting]
  procedure = "leave-one-out"      # or "fixed"
  candidates = 30
  samples = 10

`optimizer.surrogate.fitting.procedure` controls only hyperparameter fitting. Under
`leave-one-out`, the implementation fits the epistemic and aleatoric variance scales by
leave-one-out predictive likelihood. It does not change the neighbor count used by a query.

`optimizer.surrogate.neighbor-rule` controls only query-local neighbor-count selection.
Under `fixed`, `neighbors` is the exact configured count, truncated only when the live history
is smaller. Under `risk-prefix`, `neighbors` is the largest eligible prefix and the query may
select a smaller prefix. The risk-prefix rule remains experimental; it is not identified as a
proved Lepski procedure.

All four combinations are valid and tested: fixed parameters with fixed neighbors,
leave-one-out fitting with fixed neighbors, fixed parameters with risk-prefix selection, and
leave-one-out fitting with risk-prefix selection. The ambiguous historical procedure name
`leave-one-out-neighbor-search-v1` is rejected rather than silently reinterpreted.

The current 1M Metal and CUDA baselines use the original TuRBO-ENN surrogate settings:
leave-one-out fitting with fixed k = 10, 30 fitting candidates, and 10 fitting samples. The two
files whose names contain `metal-adaptive` explicitly opt into `neighbor-rule = "risk-prefix"`.
CUDA currently rejects that experimental query-local rule because its production path has not
yet been given a parity implementation.

33. ENN RESEARCH PROBLEM AND SIGNED ESTIMATION ERROR (2026-10-16)
================================================================================

Research question

Construct a derivative-free ENN optimizer whose terminal population regret or time
to a declared quality target is bounded under evaluated-token, memory, and machine
budgets. The construction includes evaluation, retained observations, surrogate and
hyperparameter fitting, uncertainty, perturbation, acquisition, trust-region geometry,
controller, initialization, and restarts. Mathematical guarantees for these components
must compose for the same objective class, observation protocol, and executable states.
No requirement of improvement after every individual evaluation is imposed.

Starting construction: the existing fitted neighbor-value estimator

The active Rust estimator is located at:
  rust/crates/semantics/src/optimizer/reliability/neighbor.rs
The older neighbor_value.rs paths in historical sections are not its current location.
Lean's Neighbor and Accuracy modules describe its real-arithmetic mean, including
the denominator floor. Exact floating-point and backend refinement remains separate.

For retained observations y_i, corresponding population values f_i, query value f_q,
weights w_i, W = sum_i w_i, and D = max(denominator_floor, W), the checked identity is:

  ENN_mean - f_q
    = sum_i w_i * (f_i - f_q) / D
      + sum_i w_i * (y_i - f_i) / D
      - (D - W) * f_q / D.

LEAN PROOF: Accuracy.errorSplit establishes this identity for the source mean.
Accuracy.splitBound bounds its absolute error by bounds on the first two signed
terms plus the explicit zero-anchor bias. Parameters, distances, and neighbor lists
may depend on observations: these are pathwise algebraic results with no statistical
independence or confidence premise.

This matters because the existing geometric envelope uses average absolute
observation errors. Even centered independent noise need not have a vanishing average
absolute error. Statistical averaging instead concerns the signed weighted noise term.
The decomposition exposes that term without presuming it concentrates.

Immediate open theorem

For a fixed population objective and the actual adaptive observation process,
establish a computable confidence envelope for fitted ENN predictions at points
used by the optimizer's decisions, uniformly over the declared token-budget scope.
If an acquisition argument requires a comparison point as well as the selected point,
the confidence event must cover both. Selection using the same observations is part
of the problem. Hyperparameter fitting and local neighbor-count selection remain
distinct decisions.

The proof has three coupled obligations:

  Geometry: bound weighted differences between population objective values using
  justified structure and a certified relationship to the sampled dissimilarities.
  Source dissimilarities are not assumed to satisfy the metric axioms.

  Noise: bound the signed weighted residual after data-dependent fitting, retrieval,
  and query selection. Independence of raw evaluation errors does not imply
  independence from weights fitted using those errors. A variance identity for
  deterministic weights is insufficient. Predictable fresh-evaluation noise and
  simultaneous confidence for predictions from historical observations are distinct.

  Work: account for observations, evaluated tokens, retained state, retrieval,
  fitting, acquisition, materialization, forward evaluation, and update. Token losses
  from one forward evaluation are not automatically independent observations of
  the objective at different parameter vectors.

Changing corpus windows does not by itself change the population objective. Fresh
windows from the same declared distribution can give noisy observations of a fixed
objective. A changing mixture, curriculum, biased selection, or conditioning rule
requires an explicit relation to that objective. This must be established from the
evaluation protocol; neither stationarity nor nonstationarity follows from a seed change.

Composition into the whole optimizer

The estimator theorem must be combined with a derived guarantee for useful candidate
access or useful information acquisition. Calibration alone does not imply progress.
A controller proof must relate its decisions to terminal quality: decreasing radius
or evidence variables alone does not establish learning. Initialization and restarts
must account for access to useful regions and their cost. These properties are to be
derived from the objective/observation class, not supplied as the desired regret rate.

Research paths remain open: local geometric estimation, decision-estimation
reductions, and decision-preserving compression. None is selected as the final
optimizer by this record. Muon remains an external empirical comparison under a
matched objective and explicit resource protocol.

  C = L^2/e + epsilon^2/a
  Rbar = sum_i w_i*R_i / W
  absolute_mean_error <= sqrt(C*(k/W + e*Rbar)).

This is a pathwise certificate, including after response-dependent fitting and
query selection. It is not a Gaussian posterior or independence calculation.

on actual error, nor proof that training must stop at an error floor. More
observations or fitting do not automatically make Rbar small; a separate
geometric argument may do so. Signed remainders are allowed when the stated
distance domination is valid; quadrature's absolute-error residual is nonnegative.

the regularity bound in those weighted units must still be justified.

41. HISTORY-STATE INTERPOLATION: CONDITIONAL CONSTRUCTION (2026-10-16)
================================================================================

The next investigation moved from screening unchanged base draws to constructing
a genuinely new parameter state from retained observations. This is a Lean
construction study, not a production optimizer decision. The new file is
  research/lean/BlckbauxResearch/Optimization/Interpolation.lean
and the fast catalogue entry is
  ./blckbaux research show interpolation

The construction uses the existing Mathlib UniformConvexOn definition from
Mathlib.Analysis.Convex.Strong. For an incumbent x and retained state y, let
delta>=0 bound F(y)-F(x). Suppose B is a proved lower bound on the convexity
modulus phi(||x-y||), and delta<B. Then the completely explicit coefficient

  t = (B-delta)/(2*B)
  z = (1-t)*x + t*y

has 0<t<=1/2 and ideal objective improvement at least

  F(x)-F(z) >= (B-delta)^2/(4*B).

The candidate may improve even when y is worse than the incumbent. The optimum
and derivatives are not inputs to the construction or its proof. This is a
full-parameter affine state operation, not a latent parameterization and not
interpolation of scalar KNN predictions. Screening's fixed-pool bound does not
apply by pretending the new z must equal one of the supplied endpoints.

chordBound invokes Mathlib's uniform-convexity inequality. envelopeMin completes
the scalar square; stepGain and proposalGain check the explicit ideal coefficient
and gain. certifiedGain allows a conservative lower bound B rather than requiring
the exact full-state modulus. General moduli are supported, not only quadratic
strong convexity. The convex region can be the particular segment; this does
NOT establish positive curvature on that segment for actual pretraining.

The trust-radius version is also constructed, rather than assumed. With r>0
and a certified upper separation U>0, use

  t = min((B-delta)/(2*B), r/U).

cappedTrust proves the ideal state obeys the declared radius when
dist(y,x)<=U. cappedGain gives ideal gain at least t*(B-delta)/2. This can be
arbitrarily smaller than the unclipped gain, so a tiny trust radius does not
inherit a radius-independent progress guarantee.

observedGap proves that endpoint observations with errors ex and ey supply
delta = observed_y-observed_x+ex+ey as a true objective-gap upper bound. The
construction requires that bound to be nonnegative and smaller than B. These
errors must refer to the SAME objective F. They are not made valid by storing
the two scalar losses, fitting ENN, or changing corpus windows. A corpus-law,
transport, or other valid observation-error argument is still required.

The sampled-geometry boundary is explicit. Under strong convexity mu>=0 and
|estimated_distance-dist(x,y)^2|<=R, sampledBend proves

  (mu/2)*(estimated_distance-R) <= (mu/2)*||x-y||^2,

and sampledRadius proves dist(x,y)<=sqrt(estimated_distance+R). Thus the SAME
two-sided quadrature certificate supplies a lower curvature benefit and an
upper trust separation. These statements do not establish a tight R, justify
self-tuned source distance normalization, or repair the known per-program
sample/materializer correspondence obligation. The objective's modulus and
regularity must be proved in this same declared metric.

executionGain charges ideal-to-executed distance error q as L*q under a
separately proved L-Lipschitz objective. executionTrust requires reserving q
inside the ideal trust radius, not adding it after clipping to the full radius.
No backend BF16 error constant, float division/reduction accuracy, or source
acceptance decision is verified by these real-arithmetic theorems. A positive
ideal margin can be entirely consumed by execution error. Guaranteed proposal
improvement is not yet guaranteed accepted progress under the actual controller.

The hypothesis is nonvacuous: squareRegular PROVES the imported StrongConvexOn
property for F(theta)=||theta-theta_star||^2 in any real inner-product dimension.
Its strong-convexity constant is 2, hence phi(r)=r^2. squareChord and squareExact
prove the chord identity and exact predicted gain, rather than merely an upper
bound. midpointGain shows equally bad points theta_star+v and theta_star-v
interpolate to theta_star. Endpoint-only screening cannot do this for nonzero v.
These are mathematical objective-family witnesses, not evidence that neural
pretraining has that geometry or that its archive contains such endpoints.

Limits are retained alongside the construction. flatModulus proves that a
constant objective admits no positive modulus at an endpoint separation;
ordinary convexity alone does not supply positive curvature. Two equal scalar
endpoint observations are compatible both with a flat objective and with a
quadratic bowl, so they do not certify the missing modulus. noCertificate proves
that, for B>=0 and delta>=B, the corresponding chord envelope cannot certify
positive gain at any nonnegative interpolation step. This is a limitation of
the certificate, not a lower bound on actual progress. Repeated interpolation
alone remains in the convex hull of its supplied states; an optimum outside
that hull needs new exploration. This is therefore NOT a complete exploration
policy, a proved useful-pair discovery law, or a horizon regret result for BLCKBAUX.
cumulativeGain telescopes any valid per-step certificates over arbitrary finite
horizons; it does not prove that their positive margins persist.

Source access is a separate, concrete obstacle to deployment. In sampled
geometry, Neighbors captures only selected BF16 parameter values.
bf16_metal/configuration.rs::release_history releases independent full rows and
the replay origin, leaves an incumbent alias, and clears exact-replay scratch.
A stored geometry row is not a materializable billion-parameter anchor. One
could stream x+t*(y-x) in O(parameter_count) arithmetic if both states were
accessible, but retention, reconstruction, and extra traffic must be accounted
for honestly. No D-by-D covariance, fixed latent span, new posterior, or hidden
full-state archive has been introduced to bypass this issue.

No Rust optimizer, Metal/CUDA kernel, TOML, data recipe, or training run changed.
The construction is not rejected or installed: it remains an explicit
conditional theorem route. It must not be promoted by assuming the two missing
properties (positive objective modulus and accessible useful retained states).
The actual KNN mean/fitting/acquisition definitions are unchanged. No comparison
with gradient training, learning-effectiveness guarantee, 200 ms achievement,
or 1000 ms achievement follows from this work.

One negative result is exact: without innovation, squared energy grows by
(s*a)^2*energy(x). No interpolation or extrapolation on that SAME chord can
reduce squared energy. This sums over all complete pairs; unpaired tails have
zero pure-rotation change. Thus the preceding interpolation theorem does not
automatically turn the existing pure tangent component into a useful move.
This is not a result about neural loss. Under an explicit centered innovation
law the module also derives the raw-candidate energy expectation, but neither
hash centering nor accepted-progress failure is inferred from that expectation.

There is also a constructive result that needs NO objective curvature, optimum
anchor, Gaussian assumption, or desired-gain hypothesis. Define

  u = s*a
  c = next - s*b*noise
  previous = (c1-u*c2, u*c1+c2)/(1+u^2).

inverseCandidate and candidateInverse prove both inverse identities for every
real coefficient choice, because 1+u^2 is always positive. equivalence packages
the explicitly constructed operation in Mathlib Equiv; fullEquivalence uses
Equiv.piCongrRight on all complete parameter pairs. Equiv.trans then supplies
inverse composition for FIXED recorded traces. A zero-padded unpaired tail is
a scalar translation, handled by Mathlib Equiv.addRight and tailError.

inverseError proves the exact quantitative refinement:

  energy(exact_reverse(executed)-previous)
    = energy(executed-ideal_forward(previous))/(1+u^2).

The inverse therefore does not amplify FORWARD execution-error energy. The
result also sums over full pairs. It does not erase forward rounding, include
reverse-computation rounding, prove exact FP16 reversibility, or imply that an
adaptive accept/reject optimizer is globally bijective. Coefficients, seeds,
tensor scales, pair addresses, and decisions from the actual trace must be
available. A seed alone does not encode arbitrary billion-parameter weights;
the complete current state is a required input to reverse reconstruction.

This gives an actual mathematical route around the previously stated full-state
access obstacle: approximate reconstruction from the current state and recorded
operations, rather than an additional dense history checkpoint. Reconstructing
only selected parameter pairs could support refreshed sampled geometry as well

remain open. For R recorded steps, full reconstruction uses O(D*R) pair work,
and reconstructing S selected pairs uses O(S*R), plus the separately counted
noise generation/metadata work. No constant-time replay or millisecond budget
is claimed. This result does not yet prove useful perturbations or a pretraining
regret rate, but unlike the earlier gain hypotheses it constructs an inverse

RecentMemory.lean models the exact logical ID-set rule of the implicit archive:
when full, evict the oldest observation other than the incumbent, then insert
the next observation regardless of acceptance. Natural IDs normalize the initial
source ID offset. Induction proves bounded capacity and latest-H-1 temporal

55. RAW PREDICTOR ERROR NOW REACHES PROJECTIVE SEED ERROR (2026-10-16)
================================================================================

The earlier transport theorems accepted a supplied value that dominated every
raw mHC score. Mixing.predict does not receive such a certificate externally;
it constructs the value by flattening the four-by-four raw matrix and applying
`foldl max`, initialized with one raw entry. Mixing.rawList and rawMax now name
that exact source operation.

The FoldMax theorems prove that the result dominates the initializer and every
listed entry and is itself attained by either the initializer or a listed
entry. Mixing.rawUpper and rawWitness specialize those facts to the matrix.
Consequently the maximum premise used by all prior seed and row-floor theorems
is now derivable from the source construction rather than assumed.

Mixing.maxBound proves the finite maximum functional is one-Lipschitz under
entrywise sup error. If two raw predictor matrices differ entrywise by at most
delta, their maxima differ by at most delta. Subtracting each matrix's own
maximum therefore gives centered-score error at most 2*delta.

SeedSensitivity carries this through the remaining source operations:

  raw sup error delta
    -> maximum error delta
    -> centered error 2*delta
    -> max(-80,.) clipped error 2*delta
    -> exponential seed-entry error 2*delta
    -> log-seed error 2*delta.

The exponential step is not a heuristic local linearization. Every clipped
input lies in (-infinity,0], and exp has derivative at most one there;
SeedSensitivity.expIic derives the corresponding LipschitzOnWith result from
Mathlib's mean-value theorem. logBound uses `log(exp(x)) = x`, so its constant
does not contain exp(80) or another reciprocal of the tiny seed floor.

This is the useful interface for the projective analysis. Absolute seed error
alone is weak for entries near exp(-80); log-seed error is uniformly controlled
and measures multiplicative/projective displacement. The remaining predictor
problem is now precise: derive delta for the raw mHC score map from state and
parameter displacement, then control which absolute diagonal representative
the twenty-step normalization selects from the nearby projective orbit.

56. SOURCE MHC PARAMETERS NOW DETERMINE RAW AND LOG-SEED ERROR (2026-10-16)
================================================================================

The raw-score delta in section 55 is no longer an opaque global predictor
constant. Mixing now names the exact source RMS scale, normalized state,
residual dot product, and residual raw-logit matrix. Mixing.predict calls those
definitions directly, so the proof and forward semantics share one expression.

MixingSensitivity.dotSplit proves the exact finite-dimensional identity

  dot(W2,z2) - dot(W1,z1)
    = dot(z2-z1,W2) + dot(z1,W2-W1),

where z is the source RMS-normalized stream state. The theorem separates two
different phenomena that cannot be collapsed without losing the architecture
of the argument:

  * direct movement of the residual predictor weights;
  * state movement propagated from all preceding forward operations.

rawSplit then adds the residual bias and group-control terms. Under entrywise
bounds B for bias movement, C for control movement, Q for incumbent control,
E for normalized-state movement, W for candidate predictor weights, and P for
predictor-weight movement, sourceBound proves raw-logit error at most

  B
  + C * n * sqrt(n) * W
  + Q * n * (E * W + sqrt(n) * P),

with n = streams*width. This is not an assigned Lipschitz constant: every term
comes from the source expression and an exact product decomposition.

The apparent normalized-activation cap is discharged internally.
MixingSensitivity.normCap proves directly from the source epsilon-RMS formula
that every normalized state entry has magnitude at most sqrt(n). It invokes
finite nonnegative sums, square-root identities, and ordered division from
Mathlib. No activation measurement or distributional assumption is used.

The entrywise estimate above is valid but unnecessarily loose. gridCauchy and
normEnergy supply the Euclidean version. If S is squared normalized-state
movement, W is candidate predictor-weight energy, and P is predictor-weight
movement energy, uniformRaw proves the sharper radius

  B + C * sqrt(n * W) + Q * (sqrt(S * W) + sqrt(n * P)).

uniformLog carries twice this radius to every log-seed entry. The formal
interface therefore accepts block/Frobenius-style energy certificates instead
of paying n for every entrywise sum.

Finally seedLog composes sourceBound with the maximum, clipping, exponential,
and logarithmic seed results. The same explicit parameter/state expression,
multiplied by two for independent maximum centering, bounds each log-seed
entry. The chain now reaches from named mHC tensor movements to the projective
geometry consumed by finite Sinkhorn.

This result changes the remaining obligation. Raw predictor sensitivity is no
longer missing. The recursive unknown is E: how far the normalized activation
entering this mHC block moves under a full candidate parameter perturbation.
That quantity must be propagated through encoder, attention, expert, prior mHC,
and decoder operations. The other open half is converting log-seed displacement
plus endpoint residuals into an absolute difference between the two finite
Sinkhorn representatives.

57. SOURCE RMS STATE MOVEMENT HAS AN EXPLICIT LOCAL BOUND (2026-10-16)
================================================================================

The normalized-state movement S in section 56 was left as an input. For the
source RMS operation itself, that input is now reduced to incoming activation
movement. Let E(x) be the sum of squared entries across the complete
streams-by-width state, n the number of entries, and

  r(x) = sqrt(E(x)/n + 1/100000).

The source operation is N(x)=x/r(x). NormSensitivity.scaleSplit proves the
exact identity

  1/r(y) - 1/r(x)
    = (E(x)-E(y)) / (n*r(x)*r(y)*(r(x)+r(y))).

energySplit proves E(x)-E(y)=<x-y,x+y>. energyShift then bounds its magnitude
by sqrt(E(x-y)*E(x+y)). Define R(x,y) as this last square root divided by the
denominator above. scaleShift proves |1/r(y)-1/r(x)| <= R(x,y). None of these
facts requires an activation-range hypothesis.

stateSplit separates N(y)-N(x) into (y-x)/r(y) and the scale change applied to
x. The checked stateBound theorem gives

  E(N(y)-N(x)) <= 200000*E(y-x) + 2*R(x,y)^2*E(x).

The 200000 is twice the reciprocal of the exact source epsilon; it is a safe
worst-case constant, not a claimed tight sensitivity or a fitted value. R is
local to the two actual states and exposes the denominator conditioning. The
theorem closes the RMS-normalization subproblem at the exact-real level. It
does not yet bound E(y-x) from a full parameter perturbation. That needs the
encoder, attention, expert, earlier mHC, and decoder propagation. It also
does not show that any perturbation is useful, that ENN memory makes a correct
decision, or that multiple rounds reduce pretraining regret.

58. RETAINED ENN REWARD AND STRICT SCALAR COMMIT (2026-10-16)

An audit of bf16_metal/observations.rs and fbt_moe/long.rs corrected an
important sign issue. The long pretraining path stores reward = negative mean
NLL. In scalar modeled mode, it accepts only if candidate reward minus the
ask-time ENN incumbent reward is strictly greater than the calculated

loss-minimizing non-strict selector is not an exact model of this path.

EnnCommit.baseBound analyzes the source weighted ENN mean, including the

that retained parameter state, and a local true-reward difference between that
state and the present incumbent. Nonnegative source weights form a weighted
sum of those bounds. Any missing mass caused by the denominator floor is a
zero-reward anchor; its bias is charged as missing mass times the magnitude
of the true incumbent reward. This is a pathwise statement and assumes no
posterior calibration or statistical independence.

current incumbent if objective changes are bounded only on the past/current
incumbent pair and the two resulting trial states. It no longer requires a

reward error, and strict scalar threshold. Its checked commitBound theorem
proves acceptance and true NLL progress when their sum is strictly below the

60. FIXED SEEDS ARE NOT A USEFUL-MOVE PROBABILITY (2026-10-16)

The long runner derives its root proposal seed by adding the round index to
the configured seed (rust/crates/blckbaux/src/fbt_moe/long.rs). Its procedural
pool may contain four candidates, but a completed ask selects only one for
objective evaluation. Conditional on the configuration, previous state, and
round, this is a deterministic computation. Calling its noise mode Gaussian
does not itself supply a random experiment or a positive conditional chance
of improvement. A probability statement would have to specify what remains
random, such as a root seed sampled before the run, and carefully handle
conditioning on the resulting history.

Optimization/SeedSupport.lean makes two checked facts explicit. fixedMass
shows that the selected candidate, represented by a point-mass law, has
useful-gain mass either zero or one. blindPool shows that, when a finite pool
does not exhaust the state space, there is an objective whose loss improves
at an unproposed target but not at any pool candidate. This is a no-free-lunch
obstruction for an unrestricted objective, not a claim that our actual
pretraining loss has that adversarial shape.

The source configurations must not be merged: the current 1M-token Metal
example with independent Gaussian noise uses four acquisition-scored
candidates; the causal performance configuration uses one pair-rotation
candidate. With one candidate, acquisition cannot choose among directions,
though the ENN may still affect predicted incumbent reward and other controls.
The source perturbation is block.scale * radius * noise before FP16 encoding,
not an established fixed-Euclidean-energy isotropic law. A positive result
must therefore either refine an explicit mathematical proposal law to this
source operation or derive a useful state-dependent direction under stated
objective and numerical assumptions.

61. AN IDEALIZED ISOTROPIC LAW DILUTES ENERGY (2026-10-16)
================================================================================

Optimization/ActiveEnergy.lean extends the existing Mathlib covariance
construction in Moments. For a centered isotropic proposal law, the expected
squared perturbation on any active set of m parameters is m times its common
coordinate variance. Its exact share of expected total squared movement is
m/D, where D is the full parameter count. Markov's inequality bounds the
probability of active-set energy at least t by m * variance / t for t > 0.
No Gaussianity or independence is needed after the covariance assumption.

This is not a generic proof that a high-dimensional random update cannot
improve the loss. Improvement can depend on direction, curvature, and the
entire model. It says something narrower and checkable: if a proposed success
argument requires appreciable energy in a small active set while keeping
total expected energy bounded, isotropy charges the m/D factor. Without a
verified objective condition of that kind, the energy calculation is not a
regret bound. If variance is instead held constant as D grows, expected total
energy grows with D; the source-scale and stability costs then need analysis.

The next source obligation is not to call the Metal program isotropic. It is
to calculate the per-block covariance induced by its seeded noise and
block.scale * radius transform, including FP16 encoding, under an explicit
distribution of root seeds. Only then can the idealized theorem inform the
actual proposal. In parallel, the objective proof must identify whether useful
pretraining moves are concentrated in an active subspace or are distributed
over many parameter directions. The formal result distinguishes these cases
without assuming either is true.

Verification: squareMean, activeMean, energyShare, and activeTail pass
./blckbaux research check and report only propext, Classical.choice, and
Quot.sound.

63. THE SOURCE SCALE CHANGES THE ENERGY ALLOCATION (2026-10-16)

formula for the block-scaled Metal proposal. The source's pre-rounding update

the sum of metric weight * block scale squared over that set. Independence is
not needed. The source generator's seed distribution and FP16 rounding still
require refinement; the theorem does not attach a probability to the fixed
configured run. This replaces a misleading direct m/D extrapolation with a
testable source-shaped quantity. The remaining objective question is whether
the weight/scale allocation reaches parameter changes that matter to the
entire evaluation window, not merely whether the physical changed count is
nonzero or one token routes to a particular expert.

Observation and evidence vocabulary

A perturbation is the proposed parameter displacement. A candidate is its
materialized, encoded parameter state. An evaluation is a completed forward
score on a declared data condition. An update is a committed replacement of
the incumbent after tell. A pool of four can still produce one objective
evaluation. The long path's reward is negative mean next-token NLL; the
modeled scalar margin compares a measured candidate reward with an ask-time
ENN estimate of the incumbent. The empirical threshold and scorer variance
do not certify the unobserved incumbent's current-window reward. A vector
policy may override the scalar decision. The source update may improve a
single window yet worsen the full corpus objective. `accepted` is an
implementation event, not a theorem about corpus learning.

The obstruction

Minimize a fixed population objective f. A retained record describes source a,
move m, trial b = apply(a,m), and a sound gain lower bound g <= f(a)-f(b).
At current state x, the construction uses B >= |f(x)-f(a)| and a nonnegative
trial transport allowance C. Its proposed lower gain is q = g-B-C.

Without any geometric or differentiability assumptions,

  g <= f(a)-f(b),   f(a)-f(x) <= B
  imply q <= f(x)-f(b)-C.

Consequently f(x) <= f(b) implies q <= 0. This includes the immediate reuse
point x=b. It also includes every earlier accepted record when subsequent
accepted updates have not increased the population objective. Taking an argmax
over more such records cannot produce a strictly positive q. The strictly
positive-threshold retained branch cannot fire in that regime. At threshold
zero a zero bound can qualify, but it certifies no positive gain.

This does NOT prove that the actual stochastic pretraining path is population-
monotone, that every retained trial was accepted, that replay cannot help, or
that the runtime's lack of improvement has this cause. It falsifies one proposed
mathematical route in a precisely specified, desirable regime. The existing
conditional Lean theorems remain true; their positive-usefulness premise cannot
be supplied there by this bound.

Exact example: f(u)=(u-3)^2, a=0, m=1, b=x=1. The observed exact historical
gain is 9-4=5. Reusing m gives f(1)-f(2)=4-1=3. Yet the exact separate shifts
are B=5 and C=3, so q=-3. There is no observation error or approximate-neighbor
error in this counterexample.

What survives: transport the gain itself

For a fixed move m define G_m(x)=f(x)-f(apply(x,m)). A possible research route
is to bound G_m(a)-G_m(x) directly, preserving cancellation. Merely assuming
that bound would repeat the original problem. A usable result must derive it
from an objective class and supply an observable, affordable bound.

For the explicit class f_z(x)=||x-z||^2 on any real inner-product space, the
following identities are checked below. Put v=a-z and g=||v||^2-||v+m||^2.

  gain on the next repetition = g - 2*||m||^2;
  total gain after n repetitions = n*g - n*(n-1)*||m||^2.

The second identity holds for real n as a displacement identity; natural n
gives repeated additive updates. Thus, after observing a genuinely successful
move, its next gain is strictly positive if g > 2*||m||^2. The unknown optimum
z cancels from the decrement. This is not a gradient estimate, a mirrored
evaluation scheme, or a proposal to restrict updates to selected parameters.
The identities allow arbitrary vectors m in arbitrary real inner-product
spaces. They do not provide the initial successful move or prove such a move
exists with adequate probability. Nor do they establish NLL regularity.

In this restricted class the move descriptor, its exact initial gain, its
squared norm, and the repetition index determine these gains algebraically.
Materializing the full state still incurs its parameter-dependent cost. The
identities are not evidence that a general objective admits this summary.

Literature and the sharpened search question

Lipschitz Bandits in Optimal Space, Zhu and Huang, ICLR 2025, Theorem 1:
https://proceedings.iclr.cc/paper_files/paper/2025/file/06b1652d342f3677b412951f79740475-Paper-Conference.pdf
The theorem gives zooming-dimension-dependent cumulative regret and logarithmic
memory for its specified algorithm. Controlled revisits replace storage of all
regional decisions. This supports investigating alternatives to complete
history retention; it does not justify the BLCKBAUX archive or gain bound. Before
transferring the bit bound, make numeric precision explicit: Lemma 1's argument
that a bounded reward sum fits in logarithmic bits needs an encoding/rounding
argument for arbitrary real rewards. Bounded magnitude alone is not finite
precision. This is a proof obligation, not a disproof of the achievable rate.

Memory--Batch Trade-offs in Lipschitz Bandits, Lyu and Huang, v2, 2026-09-28:
https://arxiv.org/html/2608.07922v2
The upper construction reconstructs active sets from fresh samples and retains
selected actions/statistics. It does not make arbitrary eviction harmless or
establish a billion-parameter runtime. Sequential evaluation remains our scope;
the paper's batch analysis is evidence about the information/memory tradeoff,
not a recommendation to change that scope.

Vector-valued self-normalized concentration inequalities beyond sub-Gaussianity,
Martinez-Taboada, Gonzalez, and Ramdas, v2, 2026-05-14:
https://arxiv.org/html/2511.03606v2
Theorem 1 constructs a nonnegative supermartingale under Assumption 1. Its
directions are predictable and its scalar noise has conditional mean zero;
subsequent usable bounds impose explicit tail conditions. Retrospectively
fitted ENN weights do not satisfy those premises merely because all records
come from earlier rounds. The missing uniform/adaptive-selection argument
remains a separate research question.

The Price of Hidden Curvature, Rajaraman and Han, v3, 2026-08-20:
https://arxiv.org/html/2607.18652v3
Theorems 1.1 and 1.2 charge adaptive learners for discovering hidden geometry
under noisy function-value feedback. They concern a specified worst-case
Lipschitz convex class, not an impossibility theorem for all structured ENN
objectives. Any proposed faster class must explain what makes its geometry
discoverable, rather than assuming known useful directions.

All four references were inspected at their primary source. Their theorem
statements and relevant assumptions were checked; their entire proofs have
not been independently verified or formalized here.

The resulting search target is now more specific: objective/operator classes
whose gain variation can be bounded from compact historical scalar evidence,

increment regularity, and sequential confidence under adaptive neighborhood
selection are search terms, not assumptions that BLCKBAUX has already satisfied.
Do not add another regret-composition theorem whose premise simply asserts
that the retained gain is useful. Do not replace the old bound in production
with the squared-distance formula without establishing its objective class.


69. LOCALIZED EVALUATION COUNTS, RETENTION, AND TERMINAL ERROR (2026-10-18)

This pass implements the localized query-count route requested after the gain-
transport audit. It does not change the production optimizer. The new result
counts evaluations needed to resolve uncertainty, rather than assuming every
proposal improves the incumbent. A failed trial can still be informative.

Files: research/lean/BlckbauxResearch/Optimization/Localized.lean is new.
KnnDecision.lean imports it and adds localizedQueries. The root already imports
KnnDecision, so no root-file edit was needed. This section and the construction
catalogue record the result. Rust, Metal, CUDA, TOML, and existing proof terms
were not changed by this pass; unrelated working-copy edits remain intact.

The statement

Fix a metric state space, objective f, reference value v, and an adaptive
sequence of complete queried states x_t. Let m_t and e_t be their prediction
means and justified error radii. On the analyzed path require

  |m_t - f(x_t)| <= e_t,
  m_t - e_t <= v + s.

Here s is an explicit selection/comparator-coverage allowance. Neither v nor
the optimizer's unknown regret is an input to the executable selector. v is
a global optimum only when that fact is separately established.

For queries in the uncertainty band w/2 < e_t <= w, the two inequalities
imply f(x_t)-v <= 2*w+s. Call this level set A_w. Let N(r,A_w) be Mathlib's
internal covering number at radius r. Require it to be finite. Suppose k
available earlier observations within 2*r of a query suffice to make its
actual analytical error radius at most w/2.

Define F_w by counting query times in this band at which at least k earlier
band observations exist within 2*r, but fewer than k nearby observations are
available in the declared memory. Then localizedCount proves

  number of queries in the band <= k * N(r,A_w) + F_w.

The proof assigns each queried point to one cover center. Two points assigned
to the same center are at most 2*r apart. The first k visits per cell cost at
most k*N(r,A_w). Any later unresolved visit contradicts the local-accuracy
premise unless the explicit memory discrepancy occurs. No objective decrease,
independent rounds, differentiability, or latent parameterization is assumed.

Observation identities, rather than unique state values, are counted. Repeated
evaluations remain distinct observations. All local counts filter strictly
earlier times. Observations outside the band can help the actual predictor;
the proof does not need them for its historical same-cell counting argument.
The state type can be a full parameter space or a restricted-domain subtype.
The result does not establish a dimension-independent covering number.

The multi-round conclusion

scaleCount sums the bound over any finite collection of uncertainty bands
covering the queried error values. Radii and required neighbor counts may
differ by scale. Overlapping bands only loosen the sum. A scale schedule must
cover the initial high errors too; they cannot be dropped from the analysis.

Apply scaleCount to Q = {t : e_t > epsilon}, including its corresponding
band-restricted recall-loss sets. If the resulting bound B is strictly less
than the total number T of objective evaluations, lowError proves that some
query has e_t <= epsilon. terminalBound then proves

  final_loss - v <= 2*epsilon + s + recommendation_penalty,

provided the actual final recommendation is no worse than each evaluated
state up to that penalty. Exact best-value recommendation has zero penalty;
selection by noisy observations needs a separately justified penalty. This
does not automatically apply to the last committed training state. In
particular, a claim about a retained recommendation must not silently become
a claim about every optimizer iterate.

This is a conditional finite-horizon terminal objective bound. It is simple
regret only with an optimum reference and the stated recommendation semantics.
It is not yet an expected-regret theorem, a cumulative-regret theorem, a
pretraining sample-complexity rate, or a token-quality guarantee.

Connection to the existing selector and source calculations

KnnDecision.localizedQueries derives the optimism premise from the existing
stable finite scan of mean-error. A represented comparison row must have a
valid error radius and lie within candidateRadius of the desired reference
state. Under the existing Lipschitz hypothesis its slack is L*candidateRadius.
Only the selected row receives an objective evaluation. The theorem does not
say the deployed singleton generator can produce such a comparison, or that
scoring or generating a large pool is cheap.

Existing KnnLearning.sourceRadius/sourceError and KnnDecision.sourceValid
provide ingredients for the retained-data implication: actual selection must
return sufficiently close observations; their values must obey the declared
error bounds; normalization must satisfy the source hypotheses. For the
geometric envelope noise+L*neighbor_radius, the scale condition would be
noise+2*L*r <= w/2. With nonzero observation error, resolution below that
envelope is not obtained by counting more neighbors alone. This is a limit
of that bound, not proof of a lower bound on the actual prediction error.

The new theorem does not discharge these source premises. In particular,
the fitted ENN standard deviation is not automatically a valid e_t. Nor does
the mere presence of k archive rows prove a successful approximate retrieval.
The meaning of memory must match available usable observations; alternatively,
prove that the actual search retrieves the neighbors counted there. Sampled
distances need their existing distortion/residual account.

Falsification and unresolved cost

Forgetting is charged at query times, not by the number of eviction events.
One eviction can matter repeatedly. forgottenCount proves that when every
query repeats the same point and memory is empty, the recall-loss count is
exactly T-k (natural subtraction), for k>0 and a nonnegative radius. Even a
one-point query region therefore gives no useful horizon conclusion from
the count alone. An archive capacity is not a bound on F_w.

A small level-set covering number also does not supply a method to find that
set. Mathlib's minimal cover is a classical proof object. Its construction
uses the objective-defined set and must not be advertised as an executable
covering oracle. Comparator access, candidate generation, distance/search
work, retention policy, full-state materialization, and source evaluation
must still be charged. No latency measurements or experiments were run.

The remaining mathematical work is specific: obtain useful covering profiles
for a justified objective/metric class; derive valid adaptive ENN error radii;
bound F_w for an actual limited-memory policy; and establish affordable
comparator access for the actual proposal law. A martingale theorem applies
only after its conditional-noise and predictability/uniformity hypotheses
are met. This pass did not assume those hypotheses for fitted ENN weights.

70. EXACT OBSERVATION INFORMATION AND CONTROLLED DELETION (2026-10-18)

Added Optimization/Envelope.lean and imported it through Retention.lean,
already in the root import closure. Retention.sourceBound applies the new
deterministic prediction bound to the existing real Neighbor.mean. No Rust,
GPU code, experiment configuration, or existing proof was replaced. These are
classical envelope results checked for this research problem, not a claim of
a new literature theorem, a successful experiment, or an achieved regret rate.

The fixed mathematical class

Fix a pseudometric state space, a nonnegative Lipschitz constant L, and a
nonempty finite set of observations (x_i,[a_i,b_i]). A compatible objective f
is L-Lipschitz and satisfies a_i <= f(x_i) <= b_i for every stored index.
Intervals must describe the same objective, even when evaluations used
different corpus windows. A fitted variance or estimated slope does not by
itself justify these assumptions. State spaces may be restricted subtypes;
no architecture, parameter dimension, derivative, or independent sampling
assumption appears in the results.

Define the two envelopes

  lower_A(x) = max_{i in A} (a_i - L*d(x_i,x)),
  upper_A(x) = min_{i in A} (b_i + L*d(x_i,x)).

feasibleIff proves that a compatible objective exists exactly when
a_i <= b_j + L*d(x_i,x_j) for every pair of records. Taking i=j also checks
interval validity. belowLip/aboveLip prove the envelopes are L-Lipschitz;
belowFits/aboveFits construct compatible objectives from this finite test.
Thus consistency is not hidden inside a vacuous universal guarantee.

valueIff proves that the possible objective values at any query x are EXACTLY
[lower_A(x),upper_A(x)]. For every value v in this interval the proof constructs
f(z)=min(max(lower_A(z),v),upper_A(z)), invokes Mathlib Lipschitz closure under
max/min, and checks every observation. Both endpoints are themselves possible.

Exact and approximate deletion

Let R be a nonempty subset of A. Provided R is consistent, retentionIff proves
that R and A admit exactly the same L-Lipschitz objectives if and only if

  a_i <= lower_R(x_i) and upper_R(x_i) <= b_i   for every i in A.

This is a finite, response-dependent criterion. A batch deletion must pass
against the final retained set; two discarded records cannot justify one
another. It preserves the compatible function class, not the ENN mean,
neighbor list, fitted hyperparameters, likelihood, or posterior distribution.

retentionBound gives a quantitative alternative. If instead

  a_i-epsilon <= lower_R(x_i),
  upper_R(x_i) <= b_i+epsilon                  for every i in A,

then, simultaneously for every query x,

  lower_A(x)-epsilon <= lower_R(x) <= lower_A(x),
  upper_A(x) <= upper_R(x) <= upper_A(x)+epsilon.

No extra loss proportional to the number of deleted records appears in this
single pruning step. Epsilon is an objective-value allowance, not a distance
radius. This pass does not prove a horizon-uniform pruning budget or a small
subset satisfying these tests. Repeated pruning cannot silently be charged
only once. Changing the metric or regularity class also invalidates automatic
reuse of old deletion tests.

The actual prediction and the limit of the information

estimateBound proves, for ANY prediction m and any compatible objective,

  |m-f(x)| <= max(|m-lower_A(x)|, |m-upper_A(x)|).

attainedError constructs a compatible objective attaining the right-hand
side. This is therefore the sharp pointwise worst-case error for this fixed
data and fixed function class, even when m depends arbitrarily on responses.
Retention.sourceBound instantiates m with Neighbor.mean, including its floor
and fitted weights. It requires no response-independent weighting argument.
This specialization is not a new guarantee that ENN estimates well: the radius
may be large, and the same envelope bounds every other real-valued estimator.
The theorem does not link supplied intervals to the source variances/values
or supplied point geometry to source distances; those correspondences and
valid evaluation-error bounds remain obligations.

Neither exact nor approximate preservation guarantees bounded memory. With
distinct exact zero observations and L>0, deleting a state at positive distance
from the retained set admits a nonzero distance-to-set objective there.
Retention.unseenLip/unseenZero already provide this witness. Conversely,
observation values can make a substantial difference: saturated proves that
L=1, f(0)=0, and f(1)=1 force f(x)=x throughout [0,1]. Interior observations of
that same function provide no additional constraints. Thus distance-only
reasoning can miss redundancy, but redundancy is not universally available.

71. HORIZON-INDEPENDENT ENVELOPE MEMORY AT FIXED RESOLUTION (2026-10-18)

Added Optimization/EnvelopeMemory.lean and its root import. The new result
separates run length from target resolution: an explicit streaming summary
preserves full-history envelopes at fixed reference states exactly, however
long the run. Its spatial approximation error does not accumulate per round.
This is not a proof that the pretraining loss has favorable geometry or that
this summary can replace the ENN posterior. Production code is unchanged.

Construction and invariant

Fix N reference states c_j, a pseudometric d, and a justified constant L.
For observations (x_i,[a_i,b_i]), maintain only the scalar pairs

  A_j = max_i (a_i - L*d(x_i,c_j)),
  B_j = min_i (b_i + L*d(x_i,c_j)).

A new observation updates A_j by max and B_j by min. recordLaw proves this
update equals complete-history recomputation at every reference. streamLaw
proves the equality after observations 0 through t for every natural t.
Queries may be adaptive; the proof does not require independent queries.
Old observation identifiers have fixed meanings and fixed intervals. Tightening
their intervals later must be supplied as new constraints; silently changing
old metadata is not covered by the invariant.

The operational update reads only the fresh observation and the resident
scalar pairs. Historical parameter vectors are not required by this summary.
They may still be needed by a separate ENN fit or another optimizer component.
The formal point/lower/upper functions index the observation stream; they are
not permission to hide an accessible full-history store in the implementation.

Query accuracy and long horizons

At a query x choose a reference c_j with d(c_j,x)<=r, and read

  lo(x) = A_j - L*d(c_j,x),
  hi(x) = B_j + L*d(c_j,x).

Let lower_t and upper_t be the exact complete-history envelopes from section
70. readBounds proves

  lower_t(x)-2*L*r <= lo(x) <= lower_t(x),
  upper_t(x) <= hi(x) <= upper_t(x)+2*L*r.

readValid proves lo(x)<=f(x)<=hi(x) for any compatible L-Lipschitz objective.
The latter validity does not require a small distance; closeness controls how
tight the interval is. For the same arbitrary estimate m, including an ENN
mean, estimateBound and radiusBound give

  |m-f(x)| <= max(|m-lo(x)|,|m-hi(x)|)
            <= max(|m-lower_t(x)|,|m-upper_t(x)|) + 2*L*r.

midpointBound gives the full-history half-width plus 2*L*r for the interval
midpoint. localError further proves

  midpoint_error <= noise + L*observation_distance + 2*L*r

when at least one recorded interval has width <=2*noise and lies within the
declared observation distance of x. That is an absolute accuracy bound, not
just a compression comparison. Its observation error need not shrink with
additional samples unless another statistical argument establishes this.

None of these bounds contains a factor of t. Unlike repeatedly pruning an
approximate archive, each update preserves the exact extremum at its original
reference, so old approximation errors are not repeatedly reintroduced. The
result does not say that the full-history uncertainty itself shrinks, or that
fixed memory supports arbitrarily improving precision. For an additional-error
allowance epsilon and L>0, r<=epsilon/(2*L) is sufficient. Finding a small cover
at this radius is the remaining geometric condition, not a supplied fact.

Optimization needs less than uniform prediction

excluded proves the following safe exclusion rule. If U is a valid upper
bound on an incumbent loss and A_j-L*r>U, then every state in the radius-r ball
about c_j has loss greater than that incumbent. The same conclusion applies
to any later incumbent whose loss is at most U, for the same fixed objective.
No accurate surrogate estimate within that excluded ball is needed. This is
not a complete exploration policy or a claim that all bad regions can be
listed cheaply. A persistent representation of excluded regions has a cost.

Checked boundary case: references cannot move for free

refinementLoss compares exact observations of f(x)=x and f(x)=-x at 0 and 1,
with L=1. Both histories have summary [0,0] at reference 0. Their complete-
history summaries at reference 1 are [1,1] and [-1,-1]. Consequently no rule
seeing only the old [0,0] summary can reconstruct both new summaries correctly.
This is a specific non-recoverability result, not a prohibition on moving
references, conservative transport, retaining extra information, or resampling.
It prevents the fixed-reference theorem being silently applied to a moving
trust region or an indefinitely refined cover.

What must hold for the pretraining application

The object being bounded must be fixed, for example the finite-corpus mean
defined in NaturalWindow. Different natural-window scores need valid intervals
for that SAME objective. A probability statement over an entire run requires
simultaneous interval validity, not merely a separate confidence claim at each
adaptively selected evaluation. Nothing in the 1M-token window size alone
establishes that property; the existing NaturalWindow obstruction still applies.

LossGeometry already bounds aligned token-loss differences by logit differences
without derivatives. It does not yet establish a useful parameter-to-loss
constant in a cheap parameter metric. A loss-induced metric is mathematically
possible but not a solution if evaluating it requires the expensive objective.
The useful condition is a small reference cover of the relevant query region
in a metric whose loss bound AND evaluation cost can be justified. No small
covering dimension for the pretraining objective is claimed by this pass.

Two real fields per reference is a slot count, not a finite-bit theorem. Exact
real values do not fit into fixed-bit machine words. Reference coordinates,
their regeneration, distance work, lookup, numeric precision, and other ENN
state all require accounting. A direct update uses N reference distances; a
dense parameter distance can cost O(N*P) for P parameters. The summary is not
a posterior distribution, and it does not preserve fitted ENN hyperparameters
or the original mean. No subsecond latency result follows from these proofs.

Theorem 1 states logarithmic-bit memory and a zooming-dimension regret bound
for their stochastic Lipschitz bandit setting. Log-Li permits controlled

Source evidence, not the module docstrings

Read rust/crates/blckbaux/src/fbt_moe/long.rs in full. Inside run(), the current
sequence is propose; causal_batch; score incumbent; capture_pair; score
candidate; then value=incumbent_value+improvement and variance=
incumbent_variance+gain_variance. observe_initial(0,0) establishes a relative
score origin, rather than storing initial negative NLL. Acceptance uses
tell_initial or paired_blocks, followed by sync. Thus a stored value is not
automatically an absolute population loss or its negative.

The module and function comments still describe scoring only the candidate.
They are not evidence for the current behavior. Git reports no local diff in
this runner; its latest modifying commit at this inspection was 2003847f.
The existing Response.Anchor.drift already identifies a single changed-window
anchor error. The new module extends the issue to arbitrary finite paths and
characterizes its exact cancellation, rather than replacing that result.

The corpus wrapper only allows a single training source on this path.
wire::PretrainDataset::causal_batch chooses an aligned, non-wrapping window by
SplitMix64(reference_seed XOR round*constant) modulo the number of origins.
reference_seed is either configured or deterministically derived from config.
No fresh conditional-uniform law is established by this source. Its sampling
unit is a complete window, not each token treated as independent. This audit
does not claim that every other accelerator/runner follows the same path.

The mathematical object

Let l(x,o) be whole-window loss at full parameter state x and origin o. Let
F(x) be the uniform mean over the finite set of aligned origins. For an
accepted-state path x_0,...,x_T with the selected origins o_t, define

  g_t = l(x_t,o_t) - l(x_(t+1),o_t),
  S_T = sum_{t<T} g_t,
  b_t = g_t - [F(x_t)-F(x_(t+1))].

errorSplit proves the exact identity

  S_T - [F(x_0)-F(x_T)] = sum_{t<T} b_t.

This is a relative-reward target consistent with a zero initial score. It is
not an assertion that negative loss, relative gain, and ENN variance coincide.
The path indexes accepted transitions; rejected proposals do not advance it.
rowBound separately proves that the error in a proposed row is at most the
current incumbent-score error plus that proposal's edge error. The result
does not refine the controller, floating-point reduction, or patch weighting.

What suffices, and what is still missing

For each edge, let r_t bound the oscillation of its improvement over origins:

  |g(x_t,x_(t+1),o)-g(x_t,x_(t+1),o_t)| <= r_t for every origin o.

errorBound then proves |S_T-[F(x_0)-F(x_T)]| <= sum_{t<T} r_t. This uses the
existing finite-mean biasBound and finite-sum triangle inequality; no random
sampling premise is introduced. Improvement oscillation can be much smaller
than raw loss oscillation, because an additive corpus-difficulty term cancels.
No small oscillation for this pretraining model has been established.

separableIff proves a precise exact boundary. Every two-edge cycle cancels,
for arbitrary states and origins, if and only if l(x,o)=f(x)+b(o). The proof
constructs f and b from one reference state and one reference origin.
separableExact then proves S_T=F(x_0)-F(x_T) for every finite path. This strong
condition is not necessary for accuracy on a particular restricted trajectory,
nor is it asserted for the neural-network loss. It characterizes universal
zero-error accumulation, not all possible useful stochastic algorithms.

movementBound gives another explicit bound: if mixed state/origin differences
are bounded by kappa*d(x,y), accumulated error is at most kappa times total
accepted path length. mixedBound derives kappa=2*L when every origin's loss
is L-Lipschitz in the same parameter metric, using Mathlib dist_le_mul without
derivatives. This fallback may be far too loose. A bounded trust region does
not bound total path length: the following cycle stays in two states forever.

A checked counterexample at every horizon

There are two states A,B and two origins a,b. Define

             a    b    corpus mean
  loss(A)    1    0       1/2
  loss(B)    0    1       1/2

Use origin a for A->B, then b for B->A, and repeat. Every evaluated transition
has exact positive improvement 1. cycleGrowth proves that the accumulated
score is T after T transitions, while population improvement is always zero.
cycleReturns proves return to the original state every two transitions;
cycleBound proves every individual loss lies in [0,1]. The counterexample
therefore needs neither observation noise nor an unbounded loss. It is an
explicit witness in the function class, not merely a proposed inequality.

This falsifies the general inference that accumulating exact paired window
improvements produces a faithful population-relative score. It does NOT prove
that the production model, proposal generator, controller, or fixed hash
schedule realizes this path. It does NOT prove that useful derivative-free
optimization is impossible. No run failure or empirical improvement is inferred
from it. A source-specific guarantee must rule out or quantitatively control
the interaction that the example exhibits.

Consequence for the memory question

The envelope summary in section 71 does not accumulate compression error with
the horizon. That result remains intact. But feeding it accumulated scores
requires intervals for those scores against ONE fixed objective. The current
proof supplies an explicit error decomposition and a valid sum bound, not a
small bound for the real pretraining objective. More retained rows cannot by
themselves remove this score error. ENN fit quality, retention quality, and
observation validity are different obligations.

73. DIRECT CORPUS INTERVALS, INCREMENTAL READS, AND LOG-LOSS AMBIGUITY (2026-10-18)

Continued beyond the path counterexample. Added Objective/CorpusMemory.lean
and Objective/CorpusWitness.lean, with root imports. The first is an explicit
streaming construction whose observation meaning is correct without treating
a selected-window score as a sample with a proved population noise law. The
second tests whether the log-loss objective itself excludes an information
obstruction. Neither modifies the deployed optimizer or launches a run.

The construction and its exact assumptions

Use the raw candidate window loss and its origin, both already available in
the inspected runner. Do not use the accumulated baseline-plus-gain value as
though it were an absolute corpus-loss observation. Fix N parameter reference
states c_j and C aligned corpus origins. Assume each origin's real loss l(x,o)
is L-Lipschitz in the chosen parameter metric. Initially require

  0 <= l(c_j,o) <= B for every reference j and origin o.

These are bounds at the reference states. They are not inferred from unseen
data or hardcoded to a measured maximum. LossGeometry can supply loss ranges
from justified logit bounds, but source-wide useful bounds remain open.

Store [A_oj,B_oj]=[0,B] at each reference/origin pair. Given one raw record
(x,o,y,eta) satisfying |y-l(x,o)|<=eta, update only its origin:

  A_oj <- max(A_oj, y-eta-L*d(x,c_j)),
  B_oj <- min(B_oj, y+eta+L*d(x,c_j)).

The code reuses EnvelopeMemory.update; old parameter vectors are not update
inputs. updateValid and streamValid prove the intervals remain valid at every
finite horizon, for arbitrary adaptive parameter and origin streams. No
independence, conditional-uniform sampler, or token-level concentration premise
is inserted. exactBound explicitly sets y=l(x,o), eta=0: own-window accuracy
is instantiated, not replaced by an assumed population-accuracy radius.
Finite-precision source evaluation needs nonzero, justified enclosures instead.

At a query x, choose a fixed reference c_j and read

  lo(x) = mean_o A_oj - L*d(c_j,x),
  hi(x) = mean_o B_oj + L*d(c_j,x).

readValid proves lo(x)<=F(x)<=hi(x), where F is the same uniform aligned-origin
mean used previously. midpointBound gives error at most (hi-lo)/2. The radius
is computed from stored intervals; there is no unknown accumulated edge-bias
sum in this read. Reference selection must be implemented and paid for. Any
reference is valid; closeness controls precision.

streamOrder and readOrder prove that more observations cannot widen the
interval at a FIXED query and reference. This does not assert monotone width
along a moving parameter path. recordBound shows that each raw constraint
survives later updates at its own origin.

Absolute loss and the ENN relative-score meaning remain distinct. gainValid
encloses F(base)-F(trial) by [lo(base)-hi(trial),hi(base)-lo(trial)]. When base
is the initial model, that is the intended target of the source's zero-
anchored rewards. relativeError bounds an arbitrary fitted ENN prediction by
its maximum distance to these endpoints. It does not equate ENN variance
with that bound, change ENN fitting, or preserve a posterior law.

When is the interval useful?

coverageBound proves that if each origin o has a historical observation x_i(o)
with its declared own-window error eta_i(o), and d(c_j,x)<=r, then

  half_width(x) <= mean_o [eta_i(o)+L*d(x_i(o),x)] + 2*L*r.

This is a sufficient condition for narrow computed intervals, with no factor
of the horizon. It does not presume that one nearby observation covers all
origins, or that the fixed hash schedule provides this geometric coverage.
Unobserved origins keep their initial reference intervals exactly (unseenExact).
Parameter regularity alone does not let observations on one origin tighten
another origin's unknown value.

Cost, including an actual algebraic improvement

The state has 2*N*C real fields, independent of observation count, plus the
references and their representations. This is not a small-memory theorem
independent of corpus size, nor a finite-bit implementation. Dense reference
distance work can still cost O(N*P) for P parameters. No 200 ms or subsecond
bound is established by these operation counts.

meanStep/meanUpdate prove that changing one origin updates each reference mean
by (new_field-old_field)/C. With two extra cached means per reference, there is
no need to rescan C origins at every query. readCached proves the displayed
formula from those means and one query/reference distance. An update touches
N origin/reference pairs and N distances; the theorem does not implement a
Rust array layout, GPU kernel, or reference-search oracle.

These cache identities are exact-real results. Repeated floating-point cache
corrections can introduce a new numerical error over time. Do not silently
transfer the no-path-bias theorem to such arithmetic; outward rounding, an
exact accumulator, or a separately bounded recomputation scheme is required.
The max/min interval state and the cached sums have different numerical issues.

The information limitation affects optimization, not only absolute offsets

For any set S of observed origins, construct two two-state objectives. Both
have loss zero on S at BOTH states. On every unseen origin, the first has
losses (0,a) and the second (a,0), with a>=0. blindBound proves [0,a] bounds;
blindRegular proves loss change <=a times distance between encoded states 0
and 1. blindAgreement proves all observed responses agree at every state.
blindOptimal proves the favored state is a true optimum. unseenRegret proves
that whichever state is recommended, one of the two compatible objectives has

  simple regret = a * number_of_unseen_origins / C.

This is a deterministic two-state decision obstruction. It is not a randomized
policy lower bound, a claim about the actual model's realizable function class,
or evidence that a measured run failed. It also does not say our interval
construction is minimax optimal. It shows exactly what cannot be guaranteed
from bounded loss and per-origin parameter regularity alone when the corpus
coverage leaves those two objectives indistinguishable.

Why merely naming cross-entropy does not remove that witness

CorpusWitness.lossExact constructs finite logits for ANY q>0 and vocabulary
size m+1 with m>=1:

  target logit = 0,
  each of m other logits = log((exp(q)-1)/m).

The partition sum is exp(q), so the existing Forward.logLoss equals q exactly.
Set q=1+the preceding bounded loss. observedExact gives response 1 on every
seen origin, for both objectives and both parameter states. meanExact proves
the common shift leaves corpus comparisons unchanged. likelihoodRegret proves
the same a*unseen_fraction regret, including a proved optimal state.

windowExact proves that repeating those token logits over any positive number
of tokens leaves the mean loss q unchanged. This includes a million-token
window, without asserting independent tokens or simulating such a run.

The witness is an arbitrary logit map. It is NOT a construction of H-Net
weights, a legal shared/overlapping corpus under the deployed forward program,
BF16 evaluation, or the live optimizer's trajectory. Actual architectural and
corpus constraints could exclude it. The precise result is that the softmax
log-loss formula and window length ALONE do not exclude it. Any stronger
pretraining-specific claim must use those additional restrictions explicitly.

81. Full-row publication and an FP16 proposal counterexample (2026-10-19)

contract::proposal now owns the shared publication predicate. The two flags
mean a nonfinite candidate and a bitwise changed storage word, respectively.
Unknown flags are rejected. A nonfinite proposal is always rejected; an
unchanged proposal is rejected unless that perturbation explicitly permits it
(the existing Metal DUST exception is preserved). Metal uses this predicate
after deriving flags from its completed full-row partials. Its existing
nonfinite squared-moment check remains in place. The exhaustive scalar test
classifies all 65,536 FP16 words; Hegel independently checks aggregate flags
over generated base/candidate arrays. These are software checks, not a new
learning or convergence theorem.

CUDA's Gaussian materialization now produces per-block flags while writing
the actual candidate. A device reduction records one word per tensor; only
those words are transferred to the host. No sampled neighbour descriptor is
used to certify full-row validity. The adapter waits for that result before
returning a candidate to the evaluator. Validation failure restores all
incumbent buffers and restores the host proposal inventory/RNG ownership,
allowing a subsequent valid materialization. Driver failures that also prevent
restoration return both errors; successful restoration is not promised after
a fatal CUDA context error.

The new storage-only fixture invokes the real Weights::materialize_gaussian
adapter with tensors of 1025, 33 and 257 words. It checks partial CTAs and
reuse of differently sized status ranges, a finite valid proposal, overflow
only at the first tensor's final coordinate, an unchanged proposal, complete
bitwise rollback and recovery after rejection. Fixture-only zero Gaussian
widths force the explicit unchanged case without modifying production tables.
This fixture is part of the existing native parity command, not an additional
training loop or an uncalled test executable.

The investigation also falsified the claimed Gaussian update-law agreement.
Metal's proposal_pair performs rounded addition. CUDA's Gaussian materializer
instead called native_discrete_fp16: if rounding left a word unchanged and
the sampled direction was nonzero, it forcibly stepped one FP16 ULP. CUDA's
own hnet_neighbor_pool did not perform that step. Thus the materialized
proposal could disagree with both Metal and its own sampled descriptor.

The Metal rounded_proposal regression runs a real Gaussian proposal from unit
FP16 weights at radius 1e-20 and verifies that the rounded-away row is not
published, weights remain unchanged and history is not extended. It passes.
The corresponding CUDA adapter regression was then compiled with the old
forced-step device function. On the T4 it exited 1 with:

  ERROR: rounded-away Gaussian proposal was not rejected: Ok(0.025408)

The number in that diagnostic is a tiny fixture's device time, not a model
latency result. The failure log is retained at
.cache/blckbaux/parity/t4-20261019/proposal-regression.log.

The forced-step function and its now-unused ULP helper were deleted. The
Gaussian materializer now rounds base-plus-delta directly, as the sampled
descriptor and Metal do. The same regression then passes. This is not an
algorithmic experiment claiming improved learning: it removes an unrequested
change to the perturbation law. Do not restore forced minimum parameter steps
under the name of the existing rounded Gaussian construction.

A separate source-level lifetime error was found in CUDA's copy_prefix.
Its safe borrowed-slice API enqueued a raw asynchronous H-to-D copy and
returned without retaining the source or waiting. cuda-core 0.3.1 explicitly
requires that source to remain alive and unmodified through completion
(simt/memory.rs::memcpy_htod_async); its own safe from_host/copy_from_host
wrappers synchronize for this reason. copy_prefix now checks context ownership,
binds the stream context and synchronizes before releasing the source borrow,
including the enqueue-error path. The adapter fixture also copies from pinned
host memory, mutates that source immediately after return and checks the
original uploaded values. Genuine asynchronous overlap requires retained
source ownership; it must not be recovered by dropping this lifetime rule.
The existing captured readout body performs no copy_prefix calls.
