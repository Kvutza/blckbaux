# BLCKBAUX black-box optimization program

**Status:** normative design and theorem ledger. This document separates implemented behavior, results inherited under explicit assumptions, and new claims that BLCKBAUX must prove. It does not claim convergence or improvement from an empirical loss curve.

## 1. Optimization object

Let \(W_t\in\mathcal W_Q\) be the resident quantized model state after round \(t\). The subscript \(Q\) matters: BLCKBAUX evaluates BF16 states, not ideal real-valued parameter vectors. Let

\[
\xi=(d,x,n_{\mathrm{prompt}},n_{\mathrm{output}},s,e,h)
\]

contain the corpus item \(d\), prompt \(x\), prompt/output allocation, sampling seed \(s\), evaluator \(e\), and hardware/backend condition \(h\). The token budget obeys

\[
n_{\mathrm{prompt}}+n_{\mathrm{output}}\le 1{,}048{,}576.
\]

A complete forward evaluation returns an outcome vector

\[
Y(W;\xi)=(Y_1,\ldots,Y_m), \qquad
F(W)=\mathbb E_{\xi\sim\mathcal D}[Y(W;\xi)].
\]

For scalar minimization, write \(L=-Y_1\). A multi-objective problem exists only when the evaluator returns independently meaningful channels. Splitting one scalar loss into administrative components does not create a multi-objective problem.

A proposal is sampled from a kernel on quantized model transitions:

\[
\widetilde W=Q(W+\Delta),\qquad
\Delta\sim K_{\phi,t}(\mathrm d\delta\mid W).
\]

The observed paired response, when both states are evaluated under the same \(\xi\), is

\[
R_t=Y(\widetilde W;\xi_t)-Y(W_t;\xi_t).
\]

This is an incumbent-candidate black-box comparison. It is not a finite-difference gradient estimate. An unpaired outcome compared with an ENN estimate of the incumbent is labeled `surrogate-incumbent`; it is not labeled as a measured pair.

## 2. Current algorithm, stated exactly

The production H-Net experiment uses a dense, independent, centered Gaussian reference law. Each standardized coordinate is generated by the 256-strip Ziggurat implementation and then multiplied by the tensor's proposal scale and the current trust-region radius. The candidate is rounded into BF16 before evaluation. The relevant code is `rust/crates/blckbaux/src/perturb.rs`, `rust/crates/blckbaux/src/bf16_search.metal`, and `rust/crates/blckbaux/src/bf16_metal`.

The resident ENN stores model-state outcomes. For generated pretraining, each new outcome is anchored by the measured paired response,

\[
\widehat Y_t(\widetilde W)=\widehat Y_{t-1}(W_t)+R_t,
\]

so acceptance and trust adaptation consume the candidate--incumbent difference measured on the same condition. The ENN does not fit raw scores from different corpus conditions as if they were directly comparable. Its conditional construction follows Bafna, Jadhav, and Sweet:

\[
\mu_i(x)=y_i,\qquad
v_i(x)=s_0^2+s_i^2+c_e d(x,x_i)^2,
\]

and combines neighbour estimates by precision weighting,

\[
w_i(x)=v_i(x)^{-1},\qquad
\widehat\mu(x)=\frac{\sum_i w_i(x)y_i}{\sum_i w_i(x)},
\qquad
\widehat v_{\mathrm{epi}}(x)=\left(\sum_i w_i(x)\right)^{-1}.
\]

The implementation also propagates reported observation variance. B+ANN is a retrieval index over compact descriptors. It returns observation identities; exact model states are regenerated or loaded for reranking. B+ANN is not the posterior.

TuRBO adapts the local radius after observations. UCB selects

\[
a_{\mathrm{UCB}}(W)=\widehat\mu(W)+\beta\widehat\sigma(W)
\]

under BLCKBAUX's reward-maximization sign convention. Thompson selection uses a shared random draw over neighbour contributions so candidates in one acquisition pool are compared under one sampled function. It is an approximate ENN posterior draw; no GP posterior-sampling theorem applies. Pareto or MORBO selection applies only to actual vector observations.

Four proposal candidates are an implementation pool, not a theoretical population size. The current round evaluates one selected candidate and therefore produces one black-box observation.

### Guarantees supplied by the TuRBO-ENN paper

Appendix C of Bafna, Jadhav, and Sweet proves substantially more than an inverse-variance heuristic, but the hypotheses matter.

For exact observations of a continuous function on a compact Euclidean domain, Theorem 1 proves:

\[
|\mu_n(x)-f(x)|
\le \sum_{i=1}^{K_n}w_{n,i}(x)\omega_f(r_{n,i}(x))
\le \omega_f(r_{n,K_n}(x)),
\]

\[
\frac{d(x,X_n)}{\sqrt{K_n}}\le \sigma_n(x)\le d(x,X_n),
\]

as well as local consistency of \(\mu_n\) and the sequential no-empty-ball property of \(\sigma_n\). Proposition 1 shows that every positive scalarization of the ENN mean--uncertainty pair has the Pseudo-BO improvement property. Together these establish the surrogate-side conditions used by the asymptotic Pseudo-BO consistency theorem.

For noisy observations, Theorem 2 gives

\[
\mathbb E[(\widetilde\mu_n-f(x))^2\mid\mathcal G_n]
\le L^2\rho_n(x)^2+\bar\sigma^2\sum_{i=1}^{k_n}\widetilde w_{n,i}^2.
\]

Consistency therefore requires both the neighbour radius to vanish and the effective inverse sample size \(\sum_i\widetilde w_{n,i}^2\) to vanish. A fixed \(k_n=K\) cannot satisfy the second condition under persistent nonzero noise because \(\sum_i\widetilde w_{n,i}^2\ge 1/K\). The stated local rate \(n^{-2/(q+2)}\) instead uses \(k_n\asymp n^{2/(q+2)}\) under the paper's small-ball conditions. Theorem 3 transfers oracle consistency to fitted variance scales only when the leave-one-out criterion converges uniformly, its target maximizer is separated, and the stated stability factors are controlled.

These results do not automatically certify the current BLCKBAUX loop. The production run uses a fresh stochastic condition across rounds, common random numbers within each paired comparison, a fixed neighbour count of 32, a four-candidate pool, quantized model states, and trust-region restriction. Pseudo-BO's cited consistency theorem assumes a compact domain, a continuous deterministic objective, the required local-consistency/no-empty-ball/acquisition properties, and exact maximization of evaluation worthiness over that domain. UCB is the closest BLCKBAUX acquisition to the proved positive scalarization. The paper explicitly does not supply an ENN Thompson sampler; BLCKBAUX's shared-neighbour draw is a separate construction. Random Pareto-front selection is likewise not covered by the scalar Pseudo-BO proposition.

## 3. Proposal measure and response record

Every evaluated generation round must emit `blckbaux.response-observation.v1`. The record contains:

- proposal distribution, seed, and selected candidate;
- total and changed BF16 coordinates;
- the fraction of coordinates surviving quantization;
- unweighted squared displacement and resident-metric radius, kept as distinct units;
- candidate, baseline, and improvement means and variances;
- the baseline type: `initial`, `paired-incumbent`, `surrogate-incumbent`, or `vector-policy`;
- separate context, prompt, drafted, evaluated, repaired, generated, and committed token counts.

The implementation is in `rust/crates/blckbaux/src/response_observation.rs` and is wired into `rust/crates/blckbaux/src/fbt_generation/rounds.rs`. It adds no TOML parameter and does not alter the hot-path acquisition rule.

## 4. Search law without distribution fitting

The dense Gaussian kernel is a mechanism for producing full-space candidates:

\[
K_t(\mathrm d\delta\mid W)=\mathcal N(0,\Sigma_{W,t}),
\]

where \(\Sigma_{W,t}\) is positive definite before quantization and block scaling defines dimensionless local coordinates. It is not a target distribution to be fitted. The black-box object remains the response function

\[
r_W(\delta)=\mathbb E_\xi[L(Q(W+\delta);\xi)-L(W;\xi)].
\]

At round \(t\), BLCKBAUX samples a finite proposal pool \(\mathcal C_t\), scores it with the chosen acquisition rule, and evaluates one selected displacement:

\[
\delta_t\in\mathop{\arg\max}_{\delta\in\mathcal C_t}
a_t\!\left(\psi(W_t,\delta);\mathcal H_t\right).
\]

The state transition is

\[
W_{t+1}=
\begin{cases}
Q(W_t+\delta_t), & \text{if the measured acceptance rule succeeds},\\
W_t, & \text{otherwise}.
\end{cases}
\]

The proposal covariance may change through measured scale or trust-region adaptation, but BLCKBAUX does not fit an exponential tilt, a target density, or importance weights over perturbations. The theoretical burden is direct: establish quantized reachability, neighbor-surrogate calibration under the declared condition law, acquisition exploration, and a finite-budget progress bound for the resulting adaptive transition process.

## 5. Geometry and identifiability

One scalar outcome cannot identify one independent response coefficient for every parameter. If a proposed response model is

\[
r_t=\phi_t^\mathsf T b+\varepsilon_t
\]

and the design matrix has a null vector \(v\), then \(b\) and \(b+v\) have identical likelihood under all collected observations. A prior can select between them; the observations cannot. Therefore a per-coordinate posterior over \(10^9\) unrelated effects is not supported by a budget of \(10^4\) scalar evaluations.

Full-space perturbation and structured inference are compatible. The production Gaussian path retains each perturbation procedurally and uses its analytic high-dimensional norm and cross-distance for ENN retrieval. This removes model-sized history replay; only the selected state is materialized. It is an explicit concentration approximation, not an exact rounded-weight distance. BLCKBAUX may later condition the posterior on a compact operator-effect descriptor \(\psi(W,\Delta,\xi)\), but such a descriptor is admissible only if nearby descriptors imply nearby response laws. The target condition is

\[
d_\psi(z,z')\rightarrow0
\quad\Longrightarrow\quad
D\!\left(\mathcal L(R\mid z),\mathcal L(R\mid z')\right)\rightarrow0
\]

for a specified probability distance \(D\). Raw tensor-family labels do not prove this property.

The next operator-level descriptor should be assembled from measurements already available during the forward pass:

\[
\psi=(
\Delta K_{\mathrm{attention}},
\Delta T_{\mathrm{mHC}},
\Delta p_{\mathrm{route}},
\Delta \ell_{\mathrm{token}},
\rho_{\mathrm{quant}},
\rho_{\mathrm{amplification}}
).
\]

Each component needs a fixed definition, scale, and estimator. Until then, procedural latent distance remains the production ENN geometry and realized distance remains a diagnostic reference.

## 6. Physics and operator theory: permitted transfer

Attention and recurrent transport can be viewed as state-dependent Markov or transfer operators acting on vector-valued signals. Antown, Froyland, and Galatolo derive optimal infinitesimal perturbations for compact Markov Hilbert--Schmidt integral operators under differentiability, conservation, and convex feasibility assumptions. Their formulae become available to BLCKBAUX only after establishing an operator space, a differentiable transfer operator, and a perturbation class satisfying those hypotheses.

Non-normality matters because a small operator perturbation can produce a large transient state change even when eigenvalues appear stable. Pseudospectral or resolvent measurements can therefore become proposal-effect coordinates. This is a sensitivity diagnostic, not an improvement theorem.

Let \(P_W\) denote the token transition operator at state \(W\). For Markov contractions in total variation, the telescoping identity gives

\[
\left\|P_{W'}^T-P_W^T\right\|_{\mathrm{TV}\to\mathrm{TV}}
\le
\sum_{j=0}^{T-1}
\left\|P_{W'}^{T-1-j}\right\|
\left\|P_{W'}-P_W\right\|
\left\|P_W^j\right\|
\le T\left\|P_{W'}-P_W\right\|.
\]

Thus a small one-step operator change can still accumulate across a million-token trajectory. This supports measuring the induced transition-operator change alongside parameter distance; it does not turn that measurement into a proposal distribution or prove improvement.

The progress theorem must concern

\[
\mathbb E[F(W_t)-F(W_{t+1})\mid\mathcal H_t],
\]

or its reward-maximization equivalent. Almost-sure global convergence without a finite-budget rate is not enough for pretraining.

## 9. Next proof and implementation sequence

1. Use the response records to test finite-precision reachability: survival, realized radius, and duplicate-state rate as functions of tensor scale and trust radius.
2. Calibrate ENN residuals separately for initialization, accepted-incumbent, and rejected-candidate observations. Do not pool these regimes until exchangeability is justified.
3. Add forward-pass observables only when each has a precise estimator and measured latency. Compare its neighbourhood continuity against exact state distance.
4. Prove or reject response alignment for that metric. Only then allow it to drive BPANN retrieval or acquisition.
5. Derive a finite-budget progress bound for the sampled-pool acquisition and acceptance process, including quantization and observation error.
6. Measure the identical paired path at 4K, 64K, and the 1,048,576-token prompt-plus-output budget. Report propose, materialize, incumbent generation, candidate generation, score, tell, memory, and every token truth label.
