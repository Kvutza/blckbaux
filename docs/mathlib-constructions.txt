BLCKBAUX CONSTRUCTION CATALOGUE
2026-10-18. List with ./blckbaux research list; read one with ./blckbaux research show TOPIC.

This catalogue describes the complete research surface, not a completed
verification of the production system. PROVED means the named Lean result is
checked under its stated hypotheses. OPEN means source correspondence or a
mathematical property is missing. PROPOSED means a research construction, not
an implementation decision or guarantee. A library import is not an invocation.
Different mathematical views may expose different findings without agreeing.

For every construction, retain the operational definition, source, exact
Mathlib object/result, inherited property, hypotheses, follow-up opportunities,
and execution obligations. Derivatives are analytical objects, not optimizer
oracle inputs. Parameter count, descriptor size, proposal count, observation
count, and token count are distinct. Complexity bounds have explicit regimes;
200 ms and 1000 ms are complete-transaction targets, not mathematical constants
inferred from an asymptotic class. Dense P-by-P matrices below are symbolic views,
not proposed billion-parameter storage layouts.

CONSTRUCTION frontier
Current: CorpusMemory.lean constructs origin-conditioned interval memory from
  raw window observations. streamValid/exactBound give corpus-loss bounds at
  every finite horizon without accumulating path bias. gainValid/relativeError
  bound relative rewards and arbitrary ENN predictions. meanUpdate/readCached
  allow incremental means and a read without a corpus-wide scan. The state is
  2*N*C real fields for N fixed references and C origins, not a small-memory
  result independent of C. coverageBound makes the remaining coverage/geometry
  error explicit. unseenRegret constructs indistinguishable bounded objectives
  with opposite preferred states. CorpusWitness realizes them with finite
  softmax logits for any vocabulary of size >=2, using Forward.logLoss; token
  repetition does not change the example. This is not deployed-H-Net or actual
  corpus realizability. See "corpus memory", "corpus witness", and section 73.
Previous: WindowPath.lean checks accumulated same-window improvements against
  the finite-corpus objective. errorSplit identifies their exact path error;
  errorBound bounds it by cross-origin improvement oscillations. separableIff
  characterizes universal two-edge cancellation as additive state/origin
  separability. cycleGrowth gives score T with zero population improvement,
  bounded losses, and a return to the same state every two transitions.
  This is a function-class obstruction, not an observed production trajectory.
  Source audit: the current Metal long runner scores incumbent AND candidate,
  stores baseline+paired_gain, and starts from zero. Its candidate-only
  docstrings are stale. No runtime change was made. See "window path" and
  handoff section 72; valid small errors for these stored values remain open.
Previous: EnvelopeMemory.lean constructs a streaming summary with two real
  scalars per fixed reference state. streamLaw proves exact agreement with
  full-history envelopes at those references for every finite horizon. At a
  query within r of a reference, readBounds/radiusBound bound the extra error
  by 2*L*r without a factor of T. localError gives noise+L*observation_distance
  +2*L*r. excluded rules out an entire ball from a validated lower bound.
  refinementLoss shows why new references cannot recover old information from
  the scalar summary alone. These are fixed-resolution, exact-real results;
  small reference covers, valid pretraining intervals, numeric refinement, and
  cheap geometry remain open. See "envelope memory" and handoff section 71.
Previous: Envelope.lean characterizes exactly the objective values compatible
  with interval observations and a fixed Lipschitz class. retentionIff gives a
  finite necessary-and-sufficient test for information-preserving deletion;
  retentionBound bounds the global envelope widening from approximate deletion.
  estimateBound/attainedError give the sharp error around any prediction, and
  Retention.sourceBound specializes the bound to the source real ENN mean.
  This does not establish a small qualifying archive, valid pretraining
  intervals/regularity, calibrated ENN variance, or affordable acquisition.
  See construction "envelope" and handoff section 70.
Previous: Localized.lean counts optimistic evaluations in near-optimal level
  sets, with an explicit charge for lost local observations. scaleCount sums
  over uncertainty bands; terminalBound converts a strict high-uncertainty
  count into a terminal objective gap. KnnDecision.localizedQueries supplies
  optimism from the existing finite selector and represented-comparator
  coverage. This route does not assume useful updates on every round. See
  construction "localized queries" and handoff section 69 for the exact bounds,
  checks, and remaining accuracy, geometry, retention, and search obligations.
Audit: 2026-10-18, handoff section 68. The separate base/trial transport bound
  cannot certify positive reuse of an accepted record when the current
  population objective is no greater than that record's trial objective.
  REPL-checked endpointBound gives q <= currentValue - trialValue - trialShift;
  expiredGain concludes q <= 0 in that regime. Thus all accepted records are
  ineligible at a strictly positive threshold along a population-monotone
  trajectory. This falsifies that exploitation route, not the validity of the
  existing conditional theorems or the usefulness of replay itself. The audit
  proofs are reproduced in the handoff, not added to the built import closure.
Earlier construction: Construct one history-conditioned, derivative-free proposal per
  transaction. A retained record contains its source state, complete parameter
  move, and a lower bound on realized population gain. At the current state,
  subtract certified source-state and trial-state transport errors; select the
  record with the largest remaining lower bound; evaluate exactly that proposal.
Source: Optimization/TransferGuide.lean, EnnCommit.lean,
  PretrainRegret.lean, PretrainHorizon.lean, Guide.lean, and the production
  history-conditioned proposal path.
Mathlib: Finite argmax, order, Lipschitz transport, probability measures,
  conditional concentration, finite union bounds, and geometric recurrences.
Proved: RetainedGuide.scoreBound turns a stored source/trial score gap minus
  their separate error radii into a population-gain lower bound, and
  RetainedGuide.chooseMax proves exact-real argmax preserves the best retained
  lower bound. RetainedGuide.progressBound transports that bound to the current
  state. RetainedGuide.commitBound proves the one selected proposal is accepted
  when its bound clears fresh score errors and the acceptance margin, and
  RetainedGuide.regretBound concludes
  `nextRegret <= (1-alpha) * currentRegret + beta` whenever the certified gain
  is at least `alpha * currentRegret - beta`. RetainedGuide.eligible and
  RetainedGuide.propose now define the complete exact-real two-case specification:
  use the
  retained argmax only when its transported lower bound clears the execution
  threshold, otherwise emit exactly one seed-indexed exploration move.
  RetainedGuide.eligibleRegret proves that the retained branch pays no proposal-
  mass penalty; RetainedGuide.exploreRegret proves that the fallback branch pays
  exactly the probability mass of a safe useful exploration atom. EnnCommit and
  PretrainRegret.sourceTail prove that, when `q` clears the ENN error, natural-
  window error, and acceptance margin and also satisfies
  `alpha * currentRegret - beta <= q`, the single committed proposal obeys
  `nextRegret <= (1-alpha) * currentRegret + beta` outside the stated window
  tail event. PretrainHorizon composes those local events over any token horizon.
Requires: Supply statistically valid error radii for the stored source and
  trial scores; refine the exact-real retained-move record and finite argmax to an
  executable finite-precision selection rule with a stated comparison error;
  prove a backend execution-refinement error and either subtract it explicitly
  or include it in the trial transport bound;
  and establish when history supplies a record whose score-corrected and
  transported lower bound meets the displayed regret inequality. The last item
  is the optimizer-existence question, not a premise that may be silently
  assumed.
Falsifier: If no retained record has a positive lower bound after transport and
  score errors, exploitation cannot be claimed to contract regret. The policy
  must take a separately analyzed exploration proposal, and its discovery law
  must pay explicitly in the rate. Failure to establish either case rejects the
  construction.
Source falsification: The one-candidate operator-BO specification gives
  acquisition a singleton, so Information.singletonLaw proves acquisition
  cannot change the represented proposal. The live non-threshold Metal
  `proposal_pair` ignores its proposal seed and maps program tags 0, 3, and 4 to
  the same `lie_flow_pair`; without a threshold object its basis seed is zero.
  Thus the current singleton direction is not selected from ENN history. The
  default latent history also releases full historical rows and exact replay
  metadata. Consequently the deployed path cannot instantiate the retained-move
  premise above. Changing only ENN fitting, acquisition, or the scalar radius
  cannot repair that missing directional dependence.
Earlier route: The exact-real Lean algorithmic object was the certificate-gated,
  history-conditioned generator RetainedGuide.propose, which emits exactly one
  proposal. For each retained move it computes
  `q = sourceScore - trialScore - sourceError - trialError
       - baseShift - trialShift`,
  select the largest q, and reapply that complete move only when q clears the
  fresh acceptance-error budget. Otherwise it emits one proposal from a
  separately analyzed exploration law. Regret and the optimum remain proof-side:
  execution does not compare q with unknown current regret. The unresolved
  mathematical result is whether the retained branch supplies
  `q >= alpha * currentRegret - beta`, or the exploration branch supplies an
  atom with that gain, with conditional probability bounded away from zero.
  RetainedGuide proves the resulting local recurrence, and PretrainHorizon
  already proves its geometric composition; neither theorem manufactures this
  gain/capture premise.
  Retaining a compact move descriptor is enough; retaining a billion-parameter
  state is not assumed. The audit above falsifies its positive-gain supply
  premise in a population-monotone regime. The localized-count route does not
  rehabilitate that bound or establish a replacement production policy.
Execution: Selection and bound maintenance must fit inside the complete 200 ms
  aspirational and sub-second operating targets. One proposed state per round
  is the research constraint; the inspected long runner also evaluates the
  incumbent. The candidate-only descriptions above are not source refinement.

CONSTRUCTION corpus memory
Definition: For each fixed parameter reference c_j and corpus origin o, keep
  [A_oj,B_oj] for l(c_j,o). A raw observation (x,o,y) with own-window error eta
  updates only that origin by max(A,y-eta-L*d(x,c_j)) and
  min(B,y+eta+L*d(x,c_j)). Initial intervals [0,B] need valid reference bounds.
Source: Objective/CorpusMemory.lean. Reuses EnvelopeMemory.update/read and
  NaturalWindow.corpusMean. This construction is not deployed Rust behavior.
Mathlib: LipschitzWith.le_add_mul, interval order, finite means, sum_eq_single,
  finite-set complements, and natural-number induction.
Proved: streamValid preserves reference validity for arbitrary adaptive streams;
  exactBound instantiates own-window accuracy with exact loss evaluations.
  readValid/midpointBound enclose corpus loss, while gainValid/relativeError
  enclose relative rewards and bound any fitted prediction without claiming
  posterior calibration. streamOrder/readOrder prove fixed-query intervals
  never widen. recordBound preserves every prior constraint at its origin.
  coverageBound gives mean(eta+L*observation_distance)+2*L*reference_distance
  when every origin has a suitable recorded point. meanUpdate and readCached
  give exact incremental averaging identities. unseenExact retains [0,B] at
  unobserved origins. blindBound/blindAgreement/blindRegular/blindMean/
  blindOptimal/unseenRegret construct two bounded, regular two-state objectives
  agreeing on all seen origins but with opposite optima; either recommendation
  has regret scale*unseen_fraction in one objective.
Requires: Useful parameter regularity in an affordable metric, valid initial
  bounds, small reference coverage error, numerical refinement, and corpus
  information. Bounds are not narrow solely because the horizon is long.
Opens: Source-value intervals from contextual evidence, independent of the
  cumulative score's bias. Reducing origin-dependent storage needs additional
  cross-origin structure or a separately justified probabilistic argument.
Execution: 2*N*C real fields plus references; optional 2*N cached means. An
  update touches N distances and N origin/reference pairs. Cached reads need
  one reference distance after reference selection. These are algebraic
  operation counts, not finite-bit or subsecond guarantees. Cached floating-
  point sums need error control. No new objective evaluations or runtime edits.

CONSTRUCTION corpus witness
Definition: For any desired q>0 and m>=1 competing tokens, target logit is zero
  and every other logit is log((exp(q)-1)/m). Use q=1+blindLoss to retain the
  unseen-origin decision ambiguity with strictly positive losses.
Source: Objective/CorpusWitness.lean; existing Forward.Algebra.logLoss/average.
Mathlib: exp_log, log_exp, one_lt_exp_iff, finite sums, positive division.
Proved: lossExact realizes q for any vocabulary of size m+1. windowExact
  preserves q under any positive number of repeated token losses. meanExact
  preserves corpus comparisons after adding 1. observedExact gives identical
  observed log loss for both objectives. likelihoodRegret gives the same
  scale*unseen_fraction simple regret with a proved optimal state.
Requires: A source-specific theory must restrict possible logit maps, corpus
  dependencies, or observation laws beyond the cross-entropy formula alone.
Opens: Testing the actual model/corpus assumptions that could exclude this
  witness; it does not imply derivative-free learning is impossible.
Execution: No actual H-Net weights, overlapping-corpus realization, BF16
  refinement, randomized-policy lower bound, or measured run is claimed.

CONSTRUCTION window path
Definition: For loss l(x,o), F(x) is the uniform aligned-origin mean.
  Each accepted edge contributes g_t=l(x_t,o_t)-l(x_(t+1),o_t) to a zero-
  anchored score S_T. The intended target is F(x_0)-F(x_T), not absolute NLL.
Source: Objective/WindowPath.lean; rust/crates/blckbaux/src/fbt_moe/long.rs,
  pretrain_data.rs, config/seeds.rs; rust/crates/artifact/src/pretrain.rs.
Mathlib: Finite sums, sum_range_succ, abs_sum_le_sum_abs, metric Lipschitz
  dist_le_mul, finite means through NaturalWindow.biasBound, and exact algebra.
Proved: errorSplit identifies S_T-[F(x_0)-F(x_T)] as the sum of edge biases.
  errorBound bounds its absolute value by the sum of improvement oscillations
  across origins, with arbitrary adaptive states and deterministic origins.
  rowBound carries incumbent error into a proposed historical row.
  separableIff proves all two-edge cycles cancel iff l(x,o)=f(x)+b(o), with
  explicit reference state/origin. separableExact gives exact corpus-relative
  scores under that condition. movementBound bounds error by kappa times path
  length when mixed state/origin differences obey that bound; mixedBound gives
  the potentially loose kappa=2*L from per-origin L-Lipschitz loss.
  cycleBound/cycleMean/cycleReturns/cycleGain/cycleGrowth construct losses in
  [0,1], equal population means 1/2, a closed alternating two-state path, and
  score T after T transitions despite zero population improvement.
Requires: Derive small mixed-difference bounds or a justified conditional
  sampling/selection argument for the real objective. Small sample scatter,
  fixed seeds, and long windows alone do not discharge these conditions.
Opens: A specific source-value accuracy obligation for the existing memory
  bounds: accumulated scores need accumulated bias control, not just an error
  allowance for the most recent window. This is separate from compression loss.
Execution: The witness is not proved realizable by the actual model/controller
  or actual hash schedule. Accepted transitions form the analyzed path;
  rejected candidate rows use rowBound. Float/patch refinement is not proved.
  No new sampler, paired evaluation, optimizer policy, or experiment was added.

CONSTRUCTION encoder

Source: Forward/Encoder.lean; hnet_encode and forward_program/hnet.rs.
Mathlib: Finset sums and real multiplication are invoked. Bilinear/linear-map
  views are PROPOSED; no information-preservation theorem is inherited yet.
Proved: Equal weighted contributions are indistinguishable; zero position

Requires: Claims about trained representations require additional properties

Opens: Joint weight/input sensitivity, null transformations, sufficient task
  information, and counterexamples to compression preserving useful information.

CONSTRUCTION normalization

Source: Forward/Algebra.rms; Regularity.rms; Mixing.mix and model RMS kernels.

Proved: Positive epsilon makes the real RMS smooth jointly along smooth weight

Requires: Full model shapes remain governed by Program.Valid. Useful sensitivity

Opens: Quantify normalization's role in perturbation propagation and compare

CONSTRUCTION selection cells
Definition: A chosen finite support is a local cell when every chosen score is
  strictly greater than every unchosen score. A margin strengthens that order
  by a common positive separation.
Source: Forward/SelectionCell.lean; intended for both Experts.selected and the
  score-ordered stages of Selection.descend/leaves.
Mathlib: LipschitzWith.dist_le_mul, the real absolute-value order, and metric
  trust-region distance.
Proved: Coordinate score changes smaller than half the incumbent separation
  preserve every chosen-versus-unchosen strict inequality. If every score is
  L-Lipschitz in parameter state, L*dist(candidate,incumbent)<margin/2 keeps
  the candidate inside the same abstract selection cell. The stronger
  ballPreserve result keeps the entire closed trust ball in that cell when
  L*radius<margin/2.
Requires: Prove that the abstract chosen set equals the source mergeSort/take
  expert set and every PISA beam/pruning set. Derive score Lipschitz constants;
  preserve mandatory, eligibility, threshold, and tie-break decisions; refine
  executed rounded arithmetic.
Opens: A local, piecewise-smooth forward sensitivity L_cell and a trust radius
  capped by the nearest selection boundary, instead of a false global
  smoothness claim across routing or sparse-attention ties.
Execution: No source top-k or PISA list equality is claimed yet.

CONSTRUCTION local sensitivity
Definition: On the closed parameter trust ball, the fixed-cell real forward

  operator norm.
Source: Forward/LocalSensitivity.lean; intended to discharge the supplied
  constant in Forward/LossGeometry.trustRange.
Mathlib: convex_closedBall and the mean-value theorem
  Convex.lipschitzOnWith_of_nnnorm_fderiv_le.
Proved: The derivative bound yields a LipschitzOnWith certificate on the whole
  trust ball. Combined with the score-margin condition, a candidate both stays
  in the incumbent abstract selection cell and has bounded forward-output
  displacement.
Requires: Differentiate the complete fixed-support exact-real Program map;
  calculate a nonvacuous derivative-norm bound; prove source selection
  refinement; add storage-rounding and executed-kernel residuals.
Opens: Derive L_cell compositionally from operator norms rather than fitting a
  calibration constant, then feed it into the logit, NLL, concentration, and
  regret chain.
Execution: The theorem converts a derivative certificate into a local bound;
  it does not yet derive that certificate for the current 1,177,756,440-slot
  source model.

CONSTRUCTION nonsmooth controls
Definition: Scalar lower flooring is x -> max(x,lower); interval clipping is
  x -> min(max(x,lower),upper), matching the mHC lambda clamp after commuting
  min/max arguments.
Source: Forward/Clipping.lean; Transport row/column floors and seed clipping;
  Mixing.predict residual-blend clipping; Decoder.advance floor.
Mathlib: LipschitzWith.max_const and LipschitzWith.min_const.
Proved: Both source-shaped scalar controls are globally one-Lipschitz despite
  nondifferentiability at their boundaries.
Requires: Compose these scalar facts through finite maximum, exponentiation on
  the actually bounded seed interval, positive normalization denominators, and
  the tensor norms used by the parameter metric.
Opens: A hybrid complete-forward proof: derivative/operator-norm bounds for
  smooth pieces and direct Lipschitz bounds for clips, rather than requiring a
  globally differentiable program.
Execution: The 1e-20 Sinkhorn denominator floor can make a naive reciprocal
  bound enormous; positivity and normalization structure must be exploited.

CONSTRUCTION projective transport
Definition: ScaleEq identifies matrices differing by arbitrary left and right
  diagonal scalings. Its division-free cross identity represents equality of
  every two-by-two matrix cross-ratio.
Source: Forward/Projective.lean; Transport.rowNormalize, columnNormalize, step,
  and finite sinkhorn iteration.
Mathlib: Finite matrices, function iteration, field normalization, and ring
  identities.
Proved: Each row pass, column pass, complete step, and arbitrary finite
  Sinkhorn result is diagonally equivalent to its input. Consequently every
  finite result preserves all division-free cross-ratio identities exactly,
  independently of the 1e-20 floor.
Requires: Bound the diagonal scaling factors in the executed four-stream
  construction and relate projective displacement of two different seeds to
  an absolute operator/output error. Add rounded-kernel refinement.
Opens: Hilbert-projective or cross-ratio sensitivity that does not charge row
  and column renormalization as independent ambient perturbations at every
  iteration.
Execution: Diagonal equivalence is not equality as a transport operator; its
  left/right scale factors still affect the mixed activation and must be
  controlled using mass/residual invariants.

CONSTRUCTION finite residual
Definition: Transport.residual is the sum of absolute row-mass and column-mass
  errors from one. The actual mHC residual matrix is the clipped convex blend
  of identity with the finite Sinkhorn result.
Source: Forward/Residual.lean; Transport.residual/blend/sinkhorn and
  Mixing.predict.
Mathlib: Finite sums, absolute-value bounds, nonnegative matrix energy, and
  convex scalar arithmetic.
Proved: Total residual bounds every individual row and column mass in
  [1-epsilon,1+epsilon]. A nonnegative matrix with residual epsilon amplifies
  squared Euclidean stream energy by at most (1+epsilon)^2. Identity blending
  scales residual exactly by lambda and gives the source-shaped bound
  (1+lambda*residual)^2 after clipping lambda into [0,1].
Requires: Bound or compute the final finite residual for all relevant predictor
  states; refine the exact-real matrix/result to the executed ordered kernel;
  control the difference between transports at two parameter states.
Opens: Supplies the transport-cap term in the mHC forward sensitivity from a
  measurable final residual instead of assuming unit operator norm.
Execution: A small final residual controls amplification of one fixed
  transport. It does not by itself bound predictor sensitivity across states.

CONSTRUCTION seed sensitivity
Definition: Mixing.rawMax is the exact finite foldl-max used by the source;
  predictor seeds subtract that maximum, clip centered scores below at -80,
  and exponentiate.
Source: Forward/Mixing.lean and Forward/SeedSensitivity.lean; Mixing.predict and
  Transport.seed.
Mathlib: Finite-list folds, max order, Lipschitz max clipping, the mean-value
  theorem, Real.exp derivative, and logarithm/exponential identities.
Proved: rawMax dominates every raw entry and is attained. It is one-Lipschitz
  under entrywise sup error. If raw predictor matrices differ by at most delta,
  centered and clipped scores differ by at most 2*delta; both absolute seed
  entries and their logarithms differ by at most 2*delta. The logarithmic bound
  is independent of exponentially small seed magnitude.
Requires: Propagate normalized-state movement through preceding layers;
  combine with SinkhornRatio for finite Sinkhorn representative sensitivity;
  refine source ordered arithmetic.
Opens: A predictorLip term in projective coordinates without dividing by the
  exp(-80) seed floor, followed by residual-controlled conversion to an
  absolute transport difference.
Execution: The source fold maximum is no longer an assumed valid maximum.

CONSTRUCTION sinkhorn ratio
Definition: Ratio factor first second asserts nonnegative matrices with
  symmetric multiplicative entrywise bounds first <= factor * second and
  second <= factor * first for factor >= 1.
Source: Forward/SinkhornRatio.lean; Transport.rowNormalize, columnNormalize,
  step, sinkhorn, and Residual.energy.
Mathlib: Ordered real division, max_le_max, pow_mul, Finset sum inequalities,
  and nonnegative quadratic forms.
Proved: Because max(floor, S_A) <= factor * max(floor, S_B) when 0 <= floor and
  1 <= factor, floored row normalization and floored column normalization each
  square the multiplicative ratio factor (factor^2) without dividing by 1e-20,
  even when weak columns hit the floor. One complete Sinkhorn step gives
  factor^4, and k steps give factor^(4^k). Clipped seeds with raw-logit error
  delta satisfy Ratio (exp(2*delta)). Any Ratio factor pair satisfies
  |second_{i,j} - first_{i,j}| <= (factor - 1) * first_{i,j}, so Residual.energy
  bounds ||(second - first) v||_2^2 <= (factor - 1)^2 * (1 + residual(first))^2 * ||v||_2^2.
  sourceDiff specializes this to k-step finite Sinkhorn outputs from raw
  predictor error delta with factor exp((4^k)*(2*delta)).
Requires: Bound the incumbent finite Sinkhorn residual or sharpen the
  worst-case 4^k multiplicative exponent on strictly positive seed cones via
  Birkhoff contraction; refine ordered F32 kernel execution.
Opens: Finite Sinkhorn transport-difference certificates that depend only on
  log-seed displacement and incumbent residual, never charging 1/floor = 1e20.
Execution: This is an exact-real finite-iteration bound; GPU reduction order
  and rounding remain separate obligations.

CONSTRUCTION mHC sensitivity
Definition: The residual logit is the source bias plus its group control times
  the dot product between RMS-normalized stream state and predictor weights.
Source: Forward/Mixing.lean and Forward/MixingSensitivity.lean; fbt_moe.metal
  and the corresponding CUDA predictor implement the same mathematical form.
Mathlib: Finite-sum triangle inequalities, exact product decomposition, square
  roots, division order, and nonnegative sums of squares.
Proved: residual-dot movement splits exactly into normalized-state movement and
  predictor-weight movement. Bias, control, predictor weight, and propagated
  normalized-state caps give an explicit entrywise raw-logit error. Source RMS
  normalization itself bounds every normalized state entry by
  sqrt(streams*width), so no measured activation-size assumption remains.
  A sharper Cauchy-Schwarz route proves total normalized-state energy at most
  streams*width and expresses raw/log-seed error in predictor-weight and
  normalized-state movement energies, without the entrywise dimension factor.
Requires: Derive normalized-state movement recursively through every preceding
  source layer and refine backend floating-point arithmetic.
Opens: Trust-radius constraints can now be stated against named parameter
  fields and propagated forward state rather than an opaque predictor
  Lipschitz constant. The formula exposes which tensor blocks dominate it.
Execution: This is an exact-real source-form certificate. It is not yet a
  useful numerical radius or a BF16/FP16 error theorem.

CONSTRUCTION RMS-normalized state sensitivity
Definition: The source predictor multiplies each incoming state entry by the
  reciprocal square root of its global mean squared activation plus 1/100000.
Source: Forward/Mixing.stateScale and normState; Forward/NormSensitivity.lean.
Mathlib: Nonnegative finite sums of squares, Cauchy-Schwarz, real square-root
  identities, ordered division, and the squared sum bound.
Proved: The squared source RMS scale is at most 100000. Its exact movement is
  the activation-energy difference divided by the source grid size and the
  product of both RMS roots and their sum. The energy difference is the inner
  product of state movement with the sum of the states and is bounded by their
  Euclidean energies. NormSensitivity.stateBound composes these facts into an
  explicit normalized-state movement bound using only the two incoming states
  and their displacement; it assumes no activation cap or fitted constant.
  Decomposing around the incumbent scale instead (`incumbentSplit`,
  `incumbentEnergy`) and canceling the candidate activation energy against the
  candidate RMS denominator in `scaleRadius` (`scaleTerm`) yields the tight
  incumbent-conditioned bound `incumbentBound`:
    gridEnergy(normState second - normState first) <=
      6 * stateScale(first)^2 * gridEnergy(second - first),
  eliminating both the worst-case 200000 (2/eps) factor and candidate energy.
Requires: Propagate incoming state displacement through the preceding source
  operations, then connect this bound to the mHC predictor and finite Sinkhorn
  representative. Prove ordered-float and storage refinement for backend use.
Opens: Incumbent-conditioned forward sensitivity where normalized-state movement
  scales with the observed incumbent RMS scale rather than 1/eps.
Execution: No useful perturbation probability or regret statement follows from
  state normalization alone.

CONSTRUCTION source ENN scalar commit
Definition: The retained weighted neighbor mean predicts incumbent reward;
  candidate reward is negative candidate NLL. Scalar mode commits only when
  candidate reward strictly exceeds predicted incumbent reward plus threshold.
Source: Optimization/Neighbor.lean, Accuracy.lean, EnnCommit.lean;
  bf16_metal/observations.rs and fbt_moe/long.rs.
Mathlib: Absolute-value triangle inequality, nonnegative weighted sums, ordered
  division, and the center-of-mass result with an explicit zero-anchor mass.
Proved: Each retained observation error and its local value difference from
  the incumbent contribute to an explicit weighted ENN reward-error radius.
  The denominator floor contributes a separate bias term. A recorded move with
  locally transported NLL gain is accepted by the strict scalar reward rule
  when its gain exceeds this radius, candidate error, and threshold. Under an
  additional retained-gain condition, the same commit contracts simple regret.
  For a fixed aligned token sequence, logitBase obtains each local NLL
  difference from per-token logit displacement using LossGeometry.averageBound;
  its factor two is independent of vocabulary size and token count.
  scheduleBase composes Sensitivity.scheduleBound across a multi-layer schedule
  with a Lipschitz decoder head to supply the per-token logit radius consumed by
  logitBase directly from Sensitivity.foldBound. windowShift and shiftSplit
  decompose each historical window observation relative to the current window;
  windowError and windowCommit prove that centering observations by a window
  baseline whose shift tracks the incumbent shift within delta cancels common
  window difficulty shift from the ENN incumbent prediction and scalar commit.
Requires: Establish the local objective differences for retained states,
  observation errors for actual natural windows, the actual neighbor/prefix
  list and fitted weights, a useful history-conditioned move, and the machine
  threshold's ordered-float refinement.
Opens: Candidate-specific ENN errors can be calculated from independently
  justified local evidence without a global parameter-space Lipschitz bound.
Execution: Vector objective control can override the scalar accept decision.
  No source calibration, move existence, or multi-round rate is proved here.

CONSTRUCTION fixed-seed proposal support
Definition: Conditional on a fixed long-run configuration and round index, the
  root proposal seed is configured_seed + round. A completed ask selects one
  candidate to evaluate, even when the procedural pool contains four rows.
Source: fbt_moe/long.rs, bf16_metal/propose.rs, bf16_search.metal;
  Optimization/SeedSupport.lean.
Mathlib: Finite probability laws, finite-set cardinality, and the pigeonhole
  principle.
Proved: The selected candidate's useful-gain mass under a point-mass law is
  exactly zero or one. For an arbitrary objective on a state space with more
  points than the incumbent and finite pool, there is a target with unit gain
  while every pool candidate has zero gain. Thus the finite proposal mechanism
  alone cannot provide a positive objective-uniform improvement guarantee.
Requires: An explicitly randomized seed experiment and a justified relation
  between its law and the source generator, or a structural objective class
  with a source-computable useful-move construction. The theorem does not
  instantiate the enormous FP16 state cardinality or prove failure of HNet NLL.
Opens: Separates genuinely probabilistic access from deterministic seeded
  execution and forces useful-perturbation hypotheses to be falsifiable.
Execution: The Gaussian generator label describes deterministic noise values
  after fixing the seed. Candidate ranking by ENN cannot create states outside
  the generated pool.

CONSTRUCTION isotropic active-set energy
Definition: Under a genuinely randomized, centered proposal law with equal
  coordinate variance, an active parameter set is any finite subset of the
  complete parameter index. Its energy is the sum of squared proposal entries.
Source: Optimization/Moments.lean and ActiveEnergy.lean. This is an idealized
  law, not the source Metal generator.
Mathlib: Covariance identity, L2 integrability, finite-sum integration, and
  Markov's inequality.
Proved: Expected active energy equals active-set size times coordinate
  variance. Its share of total expected energy is active-set size divided by
  full parameter count. The chance of active energy exceeding a positive
  threshold is at most active-set size times variance divided by that
  threshold. Neither independence nor Gaussianity is required for these
  conclusions once centered isotropic covariance is assumed. For source-style
  block-scaled noise with unit diagonal variance, scaledMean gives expected
  pre-rounding weighted energy exactly as radius squared times the sum of
  weight times scale squared on the chosen set. The m/D share applies only
  when scales and weights do not distort that share. activeShare proves that
  zeroing block scales outside an active parameter set (routedScale) concentrates
  100% of expected pre-rounding weighted energy onto the active set. deadzoneZero
  and roundingGap bound post-rounding weighted energy (roundedEnergy), proving
  zero realized energy on coordinates in the FP16 rounding deadzone and a
  quadratic perturbation bound when coordinate rounding error is bounded.
Requires: Justify any randomized law for the actual indexed seed generator;
  derive its covariance after source block scaling and FP16 encoding; identify
  an objective-dependent active set and prove that useful improvement requires
  or follows from a particular amount and orientation of movement there.
Opens: A dimension-aware obstruction and a design test for structured
  directions. With bounded total energy, isotropic active energy shrinks as
  active-set size/full dimension; increasing total energy may increase damage
  elsewhere and is not automatically a remedy.
Execution: The source radius multiplies per-block scales and then encodes to
  FP16. It is not a fixed total Euclidean-energy radius. The selection.rs
  latent_norm expression has the same weighted second-moment form before
  rounding; its source comment already warns that it is not realized geometry.

CONSTRUCTION transport

CONSTRUCTION transfer guide
Audit: Separate absolute-value transport costs erase the historical gain once
  the incumbent is no worse than the old trial. See handoff section 68 and the
  comments in TransferGuide.lean. Direct regularity of the move's gain is a
  distinct candidate route. Its squared-distance identity is REPL-checked;
  neither discovery of a useful move nor an NLL analogue is established.
Definition: Select a previously evaluated move and regenerate that same move at
  the current incumbent. The old source state, old realized gain, current source
  distance, and transported-trial distance determine retained gain.
Source: Optimization/TransferGuide.lean; source proposal seed/materializer and
  bounded observation history are the intended refinement boundary.
Mathlib: PseudoMetricSpace, LipschitzWith.dist_le_mul, absolute-value order, and
  the existing ObjectiveSearch commit and simple-regret semantics.
Proved: If the population objective is L-Lipschitz, a move with historical gain
  g retains at least g-L*(r_base+r_trial) when replayed at a nearby incumbent.
  If that retained gain clears incumbent error, candidate error, and acceptance
  margin, the source-shaped modeled rule must accept it. If retained gain also
  covers alpha times current simple regret minus beta, the committed state obeys
    r_next <= (1-alpha)*r_current + beta.
  No derivative, mirrored pair, ambient-dimensional cover, or candidate batch
  is used. This gives ENN a precise proposal role: retrieve a locally transferable
  successful move, while its prediction supplies the incumbent score envelope.
Requires: Retain or reconstruct the move seed and scale data; prove source
  regeneration correspondence; bound current-to-past and trial-to-trial distances
  in a metric with population-NLL regularity; establish the candidate window and
  ENN incumbent score errors. Historical acceptance alone is not a population-
  gain certificate when evaluation windows differ.
Opens: History-guided sequential perturbations whose contraction factor is
  derived from transported gain, instead of blind isotropic capture in 1.178B
  ambient dimensions. KNN or approximate KNN can retrieve the move source.
Execution: The current sampled archive does not yet retain proposal metadata for
  every logical observation, and the deployed calibration multiplier is empirical.
  This theorem changes no Rust, Metal, CUDA, or TOML behavior.

CONSTRUCTION pretraining regret
Definition: One transported historical move is regenerated at the current
  incumbent. ENN supplies the incumbent score and an adaptive natural token
  window supplies the only candidate score used by the single-proposal commit.
Source: Optimization/PretrainRegret.lean, TransferGuide.lean, EnnCommit.lean, and
  Objective/Adaptive.lean; long.rs is the intended transaction refinement.
Mathlib: Filtration, StronglyAdapted, conditional sub-Gaussian MGF,
  Azuma--Hoeffding, measure monotonicity, LipschitzWith, and simple regret.
Proved: If the transported population gain q satisfies both
    base_error + window_bias + window_error + margin <= q
  and
    alpha * current_regret - beta <= q,
  then the probability that the committed state violates
    next_regret <= (1-alpha)*current_regret + beta
  is at most
    exp(-(n*window_error)^2 / (2*sum(token_scales))).
  Failure is contained in candidate-loss overestimation: a certified useful
  proposal is otherwise accepted. No paired incumbent evaluation is introduced.
  For the marginal aligned-window law, sourceTail replaces abstract base scores
  and assumed window ranges with the actual source Neighbor.mean (and its 1e-12
  floor in EnnCommit.errorRadius), EnnCommit.scalarCommit, and the explicit
  whole-window NLL range [0, log(width) + 2*(logitCap + logitLip*trustRadius)]
  from LossGeometry.trustRange.
Requires: Prove the actual natural-window losses and conditional centers form
  AdaptiveBatch or refine the origin sampler to MarginalWindow.originMeasure,
  and refine recorded move regeneration to source execution.
  The current deterministic contiguous-window schedule does not discharge these
  probability premises merely by evaluating 1M tokens.
Opens: A source-auditable error budget and per-transaction alpha/beta sequence,
  followed by horizon composition in token units. The target is now an explicit
  inequality among proposal gain, transport loss, ENN error, window error, and
  acceptance margin rather than an empirical calibration multiplier.
Execution: No runtime behavior changes. Current scorer variance remains telemetry,
  not the conditional-MGF scale or a confidence radius.

CONSTRUCTION pretraining horizon
Definition: A random regret path fails locally when its next population regret
  exceeds factor*current_regret+penalty. The horizon failure event is the union
  of those transaction events; evaluated tokens are counted separately.
Source: Optimization/PretrainHorizon.lean and PretrainWorkload.lean.
Mathlib: Finite indexed unions, measureReal_iUnion_fintype_le, finite sums,
  geometric powers, and ordered-ring induction.
Proved: Outside the failure union, terminal regret is at most
    factor^steps*initial_regret + penalty*sum_{i<steps} factor^i.
  The union probability is at most the sum of the local failure probabilities,
  with no independence between adaptive transactions. A common local failure
  bound delta therefore gives terminal failure at most steps*delta. Under the
  active protocol, steps transactions equal steps*windowTokens evaluated tokens.
  strictBound proves that when local transactions achieve strict contraction
  (penalty = 0), terminal regret decays geometrically as factor^steps * initial_regret.
  geomBound proves that for factor < 1, the series sum is bounded by 1 / (1 - factor),
  establishing an asymptotic regret envelope initial_regret * factor^steps + penalty / (1 - factor).
  goalBound connects this horizon envelope directly to PretrainWorkload.tokenClock
  and PretrainWorkload.LossGoal.reached, bounding the probability of failing to
  reach a base-model loss threshold after steps*windowTokens evaluated tokens.
Requires: Instantiate every local event with PretrainRegret.regretTail or
  sourceTail and the same population objective, establish a usable factor and
  penalty uniformly or replace this uniform envelope with a varying-coefficient
  theorem, and allocate a terminal confidence budget across the intended token
  horizon.
Opens: An anytime confidence sequence can improve on the plain finite union
  budget. Token-indexed alpha/beta schedules can describe learning phases without
  treating 1,000 transactions as the pretraining goal.
Execution: This theorem does not select a horizon, assert a corpus law, or make
  one million tokens statistically independent.

CONSTRUCTION natural-window deterministic bias
Definition: Finite-corpus population loss is the uniform mean over all aligned
  contiguous-window origins. The source score is the current candidate's loss
  at one origin selected from the fixed reference seed and transaction index.
Source: Objective/NaturalWindow.lean and the causal_batch implementation in
  rust/crates/artifact/src/pretrain.rs.
Mathlib: Finite sums, the absolute-value triangle inequality, and exact field
  arithmetic.
Proved: If every aligned-origin loss for the current candidate lies within
  radius of the selected-origin loss, then selected-window error against the
  finite-corpus mean is at most radius. Candidate and origin selection may
  depend on all earlier transactions. With two origins, selected loss can be
  zero while population loss is gap/2 for arbitrary gap, so one selected window
  alone admits no nontrivial population certificate.
Requires: Establish a useful cross-origin loss-oscillation, discrepancy, or
  mixing radius for each current candidate. The source hash and 1M-token count
  establish none of those properties by themselves.
Opens: A deterministic candidate-error input to PretrainRegret, or a corpus
  partition whose local oscillations can be bounded through forward geometry.
Execution: Scores from different transactions concern different candidates and
  cannot be averaged as repeated samples of one candidate population loss.

CONSTRUCTION marginal natural-window law
Definition: The parameter-only population objective is the uniform mean of one
  candidate's whole-window loss over the finite set of aligned corpus origins.
  One stochastic observation is one complete window selected uniformly.
Source: Objective/MarginalWindow.lean, Optimization/PretrainRegret.lean, and the
  finite aligned-origin set constructed by causal_batch.
Mathlib: PMF.uniformOfFintype, PMF.integral_eq_sum, Hoeffding's lemma for a
  bounded random variable, sub-Gaussian Chernoff tails, and measure monotonicity.
Proved: Uniform-origin expected loss is exactly the finite-corpus mean. If every
  whole-window loss lies in [lower, upper], its centered loss is sub-Gaussian
  with parameter ((upper-lower)/2)^2, with corresponding upper and lower tails.
  adaptiveSubg and adaptiveTail prove this pointwise after every possible prior
  history, so the candidate may be selected arbitrarily from earlier results;
  the next origin alone must be a fresh uniform draw.
  If a transported useful proposal clears ENN incumbent error, acceptance
  margin, and a one-window error allowance, failure of the requested simple-
  regret contraction is bounded by that whole-window upper tail.
Requires: Replace or refine the fixed SplitMix/modulo schedule with a sampler
  whose conditional law is uniform over origins, prove the corpus mean is the
  intended population objective, and derive a useful whole-window loss range or
  sharper conditional MGF scale. A finite cross-entropy bound itself requires
  an explicit probability/logit floor or an equivalent model-output invariant.
Opens: A product-space adaptive sampler in which the next parameter state is
  history-measurable and the next origin is fresh conditionally uniform; sharper
  concentration from corpus mixing, stratification, or without-replacement
  sampling can replace the Hoeffding range without changing the marginal target.
Execution: Window length is not the sample count. One 1M-token forward score is
  one window observation. Its length helps only through a separately proved
  reduction in the whole-window range or variance proxy.

CONSTRUCTION contextual ENN obstruction
Definition: A pretraining observation has joint input (parameter state, corpus
  condition), while the deployed ENN pullback geometry observes only parameter
  state and therefore assigns zero distance between conditions at fixed weights.
Source: Optimization/ContextualEnn.lean, Metric.fiberNecessary, and the source
  history/causal scoring paths.
Mathlib: PseudoMetricSpace zero-distance fibers and absolute-value order.
Proved: Any finite Lipschitz certificate for the joint loss in parameter-only
  geometry forces loss to be exactly constant across all ignored conditions at
  fixed parameters. A single pair of conditions with unequal loss rules out the
  certificate for every proposed finite constant.
Requires: Choose and refine one coherent surrogate target: either include a
  corpus-condition representation in the ENN domain and prove joint regularity,
  or define the parameter-only target as a marginal over conditions and prove
  the source evaluation law estimates that marginal.
Opens: Contextual KNN metrics, quotient-safe sufficient statistics for corpus
  conditions, and deterministic online-loss analysis on the actual condition
  sequence.
Execution: Treating changing-window variation as an unnamed scalar variance does
  not establish either joint regularity or marginal unbiasedness.

CONSTRUCTION reachability
Definition: A proposal is a Mathlib Markov kernel on outcome identities,
  conditioned on retained history, incumbent state, and trust radius. An explicit
  realization map sends each outcome to its complete parameter state; a separate
  commit map retains or rejects it after scoring. Improvement sets are objective
  sublevel sets; their finite-scale geometry is represented by Mathlib covering
  and packing numbers. A finite executable `ProposalLaw` has a canonical
  probability measure and constant single-round Markov-kernel interpretation.
Source: Optimization/Reachability.lean and ObjectiveSearch.lean.
Mathlib: ProbabilityTheory.Kernel, Metric.coveringNumber,
  Metric.packingNumber, measure_mono, IsUnifLocDoublingMeasure.
Proved: Near-optimal widths are monotone; external covering complexity respects
  that inclusion. Objective regularity turns a metric ball around a better state
  into an improvement set, so any conditional ball-mass lower bound transfers to
  an improvement-capture lower bound. Capture probability multiplied by retained
  gain lower-bounds expected nonnegative improvement for any accepted-update map.
  For a safe update and a global comparator, post-update expected simple regret
  plus expected improvement equals incumbent simple regret. Hence capture, or a
  geometric accessibility certificate implying capture, gives an explicit
  one-round expected-regret decrement. If retained gain times capture mass covers
  a fixed fraction of incumbent regret, expected regret contracts by that same
  fraction. Kernel capture for the finite interpretation is exactly the existing
  finite-law `goodMass`; distinct move identities remain distinct even when they
  realize the same candidate state. The implemented acceptance rule is safe when
  its margin covers incumbent and candidate score error, and it retains captured
  gain when the gain also clears that margin. These facts compose into a finite-law
  expected-regret certificate. The implemented weighted KNN mean supplies the
  candidate half of the score-error contract under its existing deterministic
  error premises. A second certificate retains candidate-specific KNN envelopes:
  safety charges each move's local error, and gain separation is required only
  on moves inside the captured event. Thus adaptive neighborhoods need not be
  collapsed to a pool-wide worst case. Objective regularity then composes metric
  proposal mass near a better state, the candidate-specific estimator envelope,
  and acceptance into one expected simple-regret inequality. For a finite law,
  expected next regret plus expected accepted progress is exactly incumbent
  regret in real arithmetic. This identity connects the transaction theorem to
  the existing adaptive finite-oracle recurrence. A `RoundCertificate` records
  each history-dependent law, proposal realization, local geometry, score
  envelope, accepted state, and captured-gain lower bound; certificates for all
  rounds imply the existing finite-horizon geometric regret envelope. The local
  contraction factor can itself be derived: proposal mass at least p and retained
  local gain at least a times incumbent regret minus e yield factor 1-p*a and
  additive penalty p*e. It is not necessary to assign a desired rate as an axiom.
  Local doubling compares direct-state proposal mass at different scales.
  Isometric state encodings preserve internal covering complexity. A Mathlib
  metric cover by executable candidate states yields an actual nearby move;
  a lower bound on every move weight then yields a quantitative ball-mass floor.
  Covering a near-optimal set at resolution epsilon gives factor 1-p with
  additive term p times the objective modulus at epsilon. A uniform N-state
  cover specializes this to factor 1-1/N and additive floor modulus(epsilon)/N.
  Local uniform doubling transfers a positive reference-scale ball mass to a
  smaller useful ball through Mathlib's scaling constant, and then into a
  one-round regret decrement. A probability proposal assigning a common mass
  floor p to N pairwise-disjoint useful regions must satisfy N*p <= 1; hence a
  dimension-free accessibility claim needs history alignment or a restricted
  objective class rather than uniform coverage of every plausible region.
  The history-alignment route is now explicit for one proposed guide state. If
  its predicted score gap exceeds the sum of the incumbent and guide-state
  error envelopes, the guide has the declared true objective improvement. A
  nonnegative-radius ball centered on that executable guide contains the guide,
  so the guide's own proposal weight is a local mass floor. These two facts
  compose with retained gain to give the contraction factor
  1 - guide_weight*gain_share without an ambient-space coverage premise.
  A sharper sequential theorem does not introduce a metric ball at all: safety
  for every possible outcome plus acceptance and certified gain of one guide
  atom yield the same weighted contraction directly. For a deterministic
  one-proposal law, the guide weight is one and the factor is 1-gain_share. The
  implemented weighted-neighbor mean instantiates these theorems from its
  explicit denominator-floor, nonnegative-weight, and local-error premises.
  Conversely, a pool
  smaller than the external covering number cannot furnish that cover. Combining
  this cardinal obstruction with the batch planner proves that covering number
  times candidate-evaluation latency must fit accelerator width times deadline.
Requires: A doubling law alone does not provide positive mass near a useful state.
  The executable proposal still needs a quantitative history-dependent guide:
  its certified score gap after local weighted-neighbor error must retain a fixed share of
  incumbent regret, and its law weight must remain useful. Covering complexity
  still needs connection to alternative global guarantees and to a
  machine-feasible proposal construction.
Opens: Compare proposal families through capture at the same objective resolution;
  derive finite-budget rates from near-optimal geometry without identifying the
  exponent with ambient parameter count; transport results across faithful encodings.
Execution: The Markov kernel is mathematical semantics. Rust, Metal, and CUDA
  generators require refinement proofs into move identities, weights, realized
  parameter states, scores, and commits. The proved finite bridge then supplies
  their single-round kernel semantics. Source policy state, oracle feedback, and
  accepted updates still require refinement into `RoundCertificate` fields.

CONSTRUCTION guide geometry
Definition: Compare objective regret with distance to an optimum in a declared
  task metric, and ask whether the history-conditioned proposal contracts that
  distance. The optimum is proof-side data and is not passed to the optimizer.
Source: Optimization/Guide.lean and Optimization/Information.lean.
Mathlib: PseudoMetricSpace, dist_nonneg, finite weighted sums, and ordered-ring
  arithmetic.
Proved: No fixed proposal retains any positive share of simple regret for every
  unrestricted objective when an unproposed state can contain the optimum. For
  a structured class, if lower*distance is at most regret, regret is at most
  upper*distance, the proposal contracts distance by ratio, and
  upper*ratio <= factor*lower, then proposed regret is at most factor times
  incumbent regret. Candidate-specific score accuracy and a sufficiently
  separated acceptance margin transport this fact to the committed finite-law
  update. A stochastic guide pays only its proposal weight in the resulting
  factor; a deterministic guide pays no probability-mass penalty. An explicit
  target-directed perturbation is step*(anchor-incumbent), while its update is
  incumbent plus that perturbation. If the anchor's relative distance error is
  estimate and step lies in [0,1], the proved distance-factor bound is
  1-step+step*estimate. Its induced regret factor is
  upper*(1-step+step*estimate)/lower and is strictly below one when the numerator
  before division is strictly below lower. For a squared-distance objective,
  one dense signed direction has exact progress
  2*step*inner(best-incumbent,direction)-step^2*norm(direction)^2. A positive
  step therefore improves with one evaluated candidate when alignment exceeds
  the step-energy threshold; this does not require all coordinate signs to be
  positive or a mirrored candidate. Scalar candidate scores do not
  estimate the optimum state: pointwise score error, approximate minimization,
  and one comparison candidate within a certified radius instead bound the
  selected parameter state's distance to the optimum. A relative budget on
  coverage, both local score errors, and selection slack makes that selected
  state a valid perturbation anchor.
Requires: Identify a pretraining objective class and a computationally usable
  metric satisfying the two-sided growth bounds. Prove that the proposal derived
  from retained history supplies a comparison candidate with sufficient metric
  coverage; prove the weighted-neighbor score errors and selection slack fit the
  selected-anchor relative-distance budget; and prove the resulting objective
  gain clears the executable acceptance margin.
Opens: Quotient and symmetry-aware metrics, learned metrics with proof-side
  distortion bounds, local rather than global growth, variable contraction,
  and alternative structural routes that do not use metric growth.
Execution: This is a candidate theorem route, not a claim that Euclidean
  parameter distance describes the source model or that the current proposal
  satisfies contraction.

CONSTRUCTION pair rotation
Definition: The source program uses J(x,y)=(y,-x), forms
  next=state+s*(a*J(state)+b*noise), and rounds to FP16. The signed scale is
  s=sign*leaf.scale*radius. The mixture has a=0.7 or 0.3 and b=(1-a)*0.02
  in source floating arithmetic. The actual program is not a learned matrix
  commutator, a geodesic construction, or exact orthogonal multiplication.
Source: Optimization/PairRotation.lean; bf16_search.metal::proposal_pair.
  The canonical TOML generator is pair-rotation, replacing the misleading
  lie-operator name. LieOperator.lean remains a separate matrix-theory view.
Mathlib: Real ordered-field/ring identities, Finset sums, and finite proposal
  laws. No derivatives, isotropy, or Gaussian posterior are required.
Proved: The complete real pair-energy expansion retains noise cross terms.
  With b=0, E(next)-E(state)=(s*a)^2*E(state), where E(x,y)=x^2+y^2.
  No coefficient on that same chord, even an extrapolation coefficient,
  reduces E. The result sums over all complete pairs; an unpaired source tail
  has zero pure-rotation change. Under a separately proved centered finite
  innovation law, expected raw energy is
    (1+(s*a)^2)*E(state)+(s*b)^2*expected_noise_energy.
  These are exact source-shaped real results, not assumed useful-move bounds.
Requires: No conclusion about pretraining loss follows from squared energy.
  The raw expectation does not bound progress after accept/reject. Hash/noise
  centering and backend rounding semantics are not proved by these identities.
Opens: Use the actual operator rather than transferring orthogonal-matrix
  properties to an additive Euler step. See inverse for a constructive property
  of this SAME operator, without an objective-curvature assumption.
Execution: A regression reproduced different sampled and evaluated FP16 words
  on the canonical one-candidate Gaussian program. Sampled geometry, scalar and
  initial proposal paths, pool evaluation, and selected materialization now
  share proposal_pair and a canonical seed operation. The sample pipeline uses
  the materializer's arithmetic mode. Tests cover 1x1/1x4/2x2/4x1 layouts,
  Gaussian/Rademacher, independent/pair-rotation methods, changing roots,
  odd/singleton tensor boundaries, full materializations, and archived samples.
  These are source/regression checks, not a Lean compiler or GPU ISA proof.
  Unsupported pair-rotation geometry/distributions fail validation. No CUDA
  implementation of this program is claimed; its adapter rejects partial TOMLs.

CONSTRUCTION lie algebra generator and pairwise span
Definition: Commutator [G, C] = GC - CG of weight Grammian G=W^T W and activation
  covariance C generates so(n). Elementary pairwise rotation generators
  pairGen(i, j) = single(i, j, 1) - single(j, i, 1) rotate coordinate i into j.
Source: Optimization/LieOperator.lean::commutatorSkew, memSo, pairGen, pairSkew,
  pairSo, pairComm, pairSum, skewTrace, frobeniusInvariant.
Mathlib: LieAlgebra.Orthogonal.so, Matrix.single, transpose_single, single_mul_single_same,
  single_mul_single_of_ne, Fintype.sum_eq_single, Matrix trace.
Proved: [G, C]^T = -[G, C] and belongs to so(n) (memSo). Pairwise generators are
  skew-symmetric and belong to so(n) (pairSkew, pairSo). The commutator of
  adjacent pairwise generators yields the composed generator:
    [pairGen(i, j), pairGen(j, k)] = pairGen(i, k) (pairComm).
  Every skew-symmetric matrix decomposes as a weighted sum of pairwise generators:
    A = (1/2) * sum_{i, j} A_{i, j} * pairGen(i, j) (pairSum),
  proving that pairwise rotations generate the entire Lie algebra so(n).
Requires: Exponentiation to exact orthogonal matrices requires an integration or
  geodesic step; finite FP16/BF16 representation introduces deadzones.
Opens: Connect pairwise commutator generators directly to multi-round reachability
  in the discrete low-precision parameter space.
Execution: The Metal kernel uses additive Euler steps rather than matrix exponentials.

CONSTRUCTION inverse
Definition: Construct the preceding real parameter pair from the complete
  current pair, recorded innovation, and the actual fixed step coefficients.
  A seed alone is NOT an encoding of the parameters. Let u=s*a and
  c=next-s*b*noise. Then previous=(c.x-u*c.y,u*c.x+c.y)/(1+u^2).
Source: Optimization/PairRotation.lean::inverse, equivalence, fullEquivalence,
  tailEquivalence, tailError, inverseError, inverseNonexpansive, fullInverse.
Mathlib: Equiv, Equiv.piCongrRight, Equiv.addRight, Equiv.trans, real fields and finite
  sums. The source-shaped inverse is constructed, not supplied as a hypothesis.
Proved: inverseCandidate and candidateInverse hold for ALL real coefficients;
  1+u^2 is always positive. The constructed maps form an Equiv, and pointwise
  Equiv assembly covers every complete parameter pair. Fixed recorded-trace
  compositions inherit inverses. An unpaired zero-padded tail is a scalar
  translation with exact error preservation under its inverse. If executed differs from the ideal forward
  candidate, exact reverse computation has squared reconstruction error
    forward_execution_error_energy/(1+u^2),
  hence it never amplifies that error energy. The bound sums over full pairs.
  No positive objective curvature, optimum anchor, posterior, centered noise,
  or useful-proposal premise is used for the inverse and error identities.
Requires: This is not exact reversibility of FP16 encoding or an adaptive
  accept/reject optimizer. Real reverse arithmetic differs from a GPU reverse
  implementation. Account for its error, accumulated multi-step errors,
  recorded step scales/seeds/acceptance and correct source pairing/tail indexing.
  The current archive has NOT been upgraded to reverse replay.
Opens: Approximate retained-state reconstruction and history-dependent proposal
  directions without an additional model-sized checkpoint. Reconstructing only
  queried parameter pairs could permit refreshing sampled geometry without
  materializing every historical model. This is an implementation/research
  opportunity with an explicit error account, not a deployed memory guarantee.
Execution: One pair inverse has fixed arithmetic work. Reconstructing D full
  parameters through R recorded steps costs O(D*R), while selected S parameter
  pairs cost O(S*R), plus noise generation and metadata access. These are
  algorithmic operation counts, not a checked backend latency certificate.
  No O(1) history replay, exact seed-only compression, regret rate, or 200 ms
  claim follows. The learning-effectiveness question remains open.

CONSTRUCTION interpolation
Definition: Construct a new full parameter state z=(1-t)*x+t*y from an
  incumbent x and a materializable retained state y. This is interpolation of
  parameter states, NOT interpolation of scalar loss predictions, and not a
  selector restricted to returning x or y. It is a conditional construction
  study, not the deployed ENN proposal or a complete Bayesian optimizer.
Source: Optimization/Interpolation.lean. The source Neighbors archive stores
  sampled parameter values; bf16_metal/configuration.rs::release_history drops
  independent full history rows and replay origin in the sampled-geometry mode.
Mathlib: Mathlib.Analysis.Convex.Strong (module); UniformConvexOn and
  StrongConvexOn (root declarations); norm/inner-product square identities.
  Library documentation:
  https://leanprover-community.github.io/mathlib4_docs/Mathlib/Analysis/Convex/Strong.html
Proved: Let delta>=0 bound F(y)-F(x), and B>delta be a proved lower bound on
  the uniform-convexity modulus at ||x-y||. The explicit coefficient
  t=(B-delta)/(2*B) lies in (0,1/2], and the ideal gain is at least
  (B-delta)^2/(4*B). No optimum or derivative is an algorithm input. For a trust
  radius r and certified upper separation U>0, t=min((B-delta)/(2*B),r/U)
  obeys the ideal radius and retains gain at least t*(B-delta)/2. Observation
  errors give delta=observed_y-observed_x+error_x+error_y. Execution distance
  error q costs L*q under a separately proved L-Lipschitz objective; reserving
  q inside the ideal radius preserves the executed trust constraint.
  Under strong convexity mu>=0 and |sampled_distance-distance^2|<=R,
  B=(mu/2)*(sampled_distance-R) is a valid LOWER modulus bound, while
  U=sqrt(sampled_distance+R) is an UPPER separation bound. The quadrature
  certificate must concern this same metric, both states, and their actual
  materialization; a tiny raw sampled distance is not a certificate by itself.
  Whole-trajectory certified gains telescope at every finite horizon.
  Squared distance to an arbitrary optimum satisfies Mathlib StrongConvexOn
  with strong-convexity constant 2, giving modulus phi(r)=r^2; its chord
  identity and predicted ideal gain are exact in any
  real inner-product dimension. Opposite equally bad endpoints interpolate to
  the optimum, demonstrating a new state with gain unavailable to endpoint-only
  selection. This is a mathematical witness, not a pretraining result.
Requires: Prove the modulus on the chosen convex region (the segment suffices),
  not assume global strong convexity of neural-network loss. Certify endpoint
  observations against one objective, the distance residual, state access, BF16
  error, floating arithmetic, and the source acceptance rule. Construct/retain
  useful pairs repeatedly and account for their discovery; this has not been
  proved. Constant objectives admit no positive modulus, so ordinary convexity
  or two scalar endpoint observations cannot simply supply positive curvature.
  The source inverse offers a mathematical state-reconstruction route, with
  execution error and trace/cost obligations; it is not installed in the archive.
Opens: A precise history-to-parameter proposal obligation rather than assuming
  an already accurate optimum anchor. KNN may select local retained pairs;
  raw source KNN means, inverse-precision fitting, and posterior claims are not
  replaced by this construction. General moduli permit other convexity classes.
Execution: No Rust optimizer, sampler, kernel, TOML, or experiment is changed.
  The construction is NOT a complete exploration policy: repeated interpolation
  cannot leave the convex hull of the states supplied to it. Without new states
  or an appropriate existing hull it need not reach an optimum. No uniform
  gain share, end-to-end regret rate, learning effectiveness, or latency target
  follows yet. One streamed x+t*(y-x) realization uses O(parameter_count)
  arithmetic IF both states are accessible; retrieving/replaying them is a
  separate potentially dominant cost. No backend cost certificate is claimed.

CONSTRUCTION acquisition

CONSTRUCTION screening
Definition: Select one output from a finite supplied candidate family under a
  joint law that includes generation and acquisition randomness. The selected
  output alone is evaluated. Screening is distinct from learning a new proposal
  law, changing trust regions, or producing new candidates adaptively.
Source: Optimization/Information.lean; singleton source case is configured in
  performance/configs/hnet-1m-causal-1000.toml and bf16_search.metal::bf16_select.
Mathlib: Finset.single_le_sum, finite weighted sums, sum_comm, and ordered
  multiplication. These are finite union/sum bounds, not new bandit rate theory.
Proved: screenBound bounds selected expected nonnegative useful value by the
  sum of slot-wise expected useful values, without independence. screenCap
  specializes equal marginal upper bounds b to K*b. Indicators give an
  improvement-probability upper bound; positive-part true gains give an upper
  bound on accepted progress for exact accept/reject. screenBudget derives the
  necessary inequality gain*cost <= work*b when K*cost <= work. singletonLaw
  shows valid selection from one represented candidate cannot change its state.
Requires: An actual joint law, nonnegative useful value, and proved marginal
  bounds. No small marginal bound for the actual pretraining objective is
  established. Abstract work is not a wall-time or GPU-throughput certificate.
Opens: Distinguish gains from better screening from gains due to a history-
  conditioned generator changing its marginal proposal quality. Bounded
  screening cannot remove a dimension-dependent marginal upper bound by more
  than its candidate-count factor. Adaptive new proposals require their own
  marginal analysis; they are not ruled out by assigning them the old base law.
Execution: A one-scored-pilot/one-fallback prototype was tested and rejected as
  a standalone solution to proposal accessibility. Both Rust and Lean prototype
  sources were removed; only the general limitation remains. No GPU runner,
  TOML, model, or data recipe was changed. This does not reject all screening or
  establish that the current optimizer cannot learn. Invalid-score paths remain
  outside the valid singleton-selection statement.

CONSTRUCTION batch
Definition: Separate raw candidate count, effective target coverage, parallel
  batch width, sequential depth, and selector penalty.
Source: Optimization/Batch.lean and procedural pool source.
Mathlib: ProbabilityTheory.iIndepSet, iIndepSet.meas_biInter,
  MeasurableSet.iInter, measure_compl, and ordered semiring arithmetic.
Proved: Independent equal-miss candidates have joint miss probability q^N and
  hit probability 1-q^N. A dependence-agnostic theorem accepts any certified
  joint miss bound. It composes that bound with uniform score error and

  plus 2*error+slack. Equivalently, meeting benchmark regret R requires pool
  coverage at R-(2*error+slack). Repeating one candidate any nonzero number of
  times leaves the miss event unchanged. A deadline-feasible plan obeys
  candidates*evaluation_time <= batch_width*deadline.
Requires: Independence is not established for BLCKBAUX. The source proposal law,
  target event, effective diversity, actual accelerator batch width, and complete
  per-candidate evaluation cost must be supplied rather than inferred from N.
Opens: Correlation-sensitive bounds, negative-dependence designs, diversity
  objectives, adaptive batch/sequential policies, and coverage per machine cost.

CONSTRUCTION calibration

CONSTRUCTION envelope
Definition: For records (x_i,[a_i,b_i]) and fixed Lipschitz constant L, define
  lower(x)=max_i(a_i-L*d(x_i,x)) and upper(x)=min_i(b_i+L*d(x_i,x)).
  These describe compatible objective values, not a posterior distribution.
Source: Optimization/Envelope.lean; Retention.sourceBound specializes the
  prediction bound to Neighbor.mean. Existing Retention.compactChoice remains
  an obstruction to unrestricted sufficiency of the source compaction map.
Mathlib: LipschitzWith.of_le_add_mul, le_add_mul, max_const, min,
  Finset.sup'_le, le_sup', le_inf', inf'_le, exists_mem_eq_inf', metric triangle
  inequalities, and linarith. No derivative or stochastic independence enters.
Proved: feasibleIff characterizes existence by the finite inequalities
  a_i <= b_j+L*d(x_i,x_j). valueIff constructs an admissible objective for
  every value in [lower(x),upper(x)]. retentionIff proves deletion is lossless
  exactly when the retained envelopes satisfy every original interval at its
  recorded state. All witnesses must survive the deletion together.
  retentionBound relaxes those finite tests by epsilon and proves the lower
  envelope decreases by at most epsilon and the upper increases by at most
  epsilon at EVERY query. estimateBound bounds any prediction's absolute error
  by its farther interval endpoint; attainedError constructs a compatible
  objective attaining that error. saturated shows f(0)=0, f(1)=1 and L=1 force

  objective; source state/interval correspondence; useful small retained sets;
  actual distance and selection costs. sourceBound accepts arbitrary ENN
  weights/fit and does not turn its standard deviation into a valid radius.
Falsifier: Exact preservation need not allow any deletion. For distinct exact
  zero-valued observations and L>0, an omitted state at positive distance from
  retained states permits a nonzero Lipschitz extension. Retention's existing
  distance-to-archive construction supplies it. No fixed memory bound follows.
Opens: Measure information loss in objective-value units, including observation
  values rather than distance alone. This is classical envelope/set-membership
  mathematics newly checked here, not a novel regret theorem or an ENN advantage.
Execution: No production change. A direct finite deletion test uses up to
  |full|*|retained| distances; each query envelope scans the retained records.
  These are algorithmic counts, not Lean-verified costs or latency measurements.
  Changing the metric or L requires rechecking deletion validity; earlier
  deletion tests for a different class cannot be reused without another proof.
References: https://arxiv.org/html/2310.07039v1 (bounded-noise interpolation);
  https://arxiv.org/html/2606.04670v1 (LipFit, section 3). The latter's displayed
  covering-radius equality after equation (3) is not generally an equality
  conditional on fixed response values: saturated is a counterexample. See
  handoff section 70 for the distinction from a worst case over responses.

CONSTRUCTION envelope memory

CONSTRUCTION quadrature
Definition: Partition all parameter indices into strata, take one representative
  per stratum, and weight its squared displacement by stratum size and tensor
  weight. The representative map is fixed; no random-sampling law is assigned.
Source: Optimization/Quadrature.lean; bf16_metal/neighbors.rs and the

Mathlib: Finset filter partitions, finite-sum interchange, sum_erase_add,
  finite-sum absolute-value and ordered multiplication inequalities.
Proved: fullSplit counts every parameter once. errorBound bounds absolute
  full-minus-sampled squared distance by the weighted sum of unsampled counts
  times within-stratum squared-displacement oscillation. distanceUpper gives
  full <= sampled+remainder. constantExact proves exactness for constant squared
  displacement per stratum; signExact specializes it to unrounded, constant-
  amplitude unit-sign updates relative to their own base. missedEnergy gives an
  omitted-parameter counterexample to unqualified sampled-distance domination.
  distanceSquared identifies full energy with Mathlib weighted Euclidean
  distance. embedInjective/unembedEmbed prove positive weights preserve all

Execution: No resampling was implemented. Fresh indices require matching values
